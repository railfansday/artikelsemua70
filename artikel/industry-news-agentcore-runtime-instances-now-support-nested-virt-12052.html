Industry News: AgentCore runtime instances now support Nested Virtualization

🌐 Source: Amazon • 📅 19 Nov 2026 • ⏱️ 1 min read (168 words, 📖 Standard)
💡 Key Takeaways
  • Amazon Bedrock AgentCore runtime instances now support nested virtualization, so your agents can run their own virtual machines and emulators inside a session with Kernel-based Virtual Machine (KVM).
  • Recent findings suggest that you turn on nested virtualization when you create a Linux capacity provider, and agents in every session on its instances can use KVM.
  • Nested virtualization is available on supported instance types in all AWS Regions where AgentCore runtime instances are available.

Amazon Bedrock AgentCore runtime instances now support nested virtualization, so your agents can run their own virtual machines and emulators inside a session with Kernel-based Virtual Machine (KVM). Runtime instances run your agents on Amazon EC2 instances while AgentCore handles provisioning, patching, scaling, and lifecycle management. Nested virtualization serves agents that rely on tools that run in a virtual machine, such as mobile emulators or virtual machine sandboxes.

Recent findings suggest that you turn on nested virtualization when you create a Linux capacity provider, and agents in every session on its instances can use KVM. For example, your agents can run Android emulators to build and test mobile apps, or start lightweight virtual machines to isolate the code that they run. Nested virtualization works on supported Intel-based instance types, including the C7i, C8i, M7i, M8i, R7i, and R8i families.

Nested virtualization is available on supported instance types in all AWS Regions where AgentCore runtime instances are available.
