You can now copy data server-side between Amazon S3 buckets and Amazon FSx file systems with S3 Access Points

🌐 Source: Amazon • 📅 22 Nov 2026 • ⏱️ 1 min read (266 words, 📖 Standard)
💡 Key Takeaways
  • You can now use Amazon S3 Access Points to copy or move data server-side between Amazon S3 general purpose buckets and Amazon FSx file systems within the same AWS Region, making it faster, lower-cost, and easier to move your data between S3 and FSx or across FSx file systems.
  • According to recent reports, an S3 Access Point for FSx is an S3 endpoint that allows you to access the data on your Amazon FSx for NetApp ONTAP and Amazon FSx for OpenZFS file systems via the S3 API and from S3-based services and applications.

You can now use Amazon S3 Access Points to copy or move data server-side between Amazon S3 general purpose buckets and Amazon FSx file systems within the same AWS Region, making it faster, lower-cost, and easier to move your data between S3 and FSx or across FSx file systems.

According to recent reports, an S3 Access Point for FSx is an S3 endpoint that allows you to access the data on your Amazon FSx for NetApp ONTAP and Amazon FSx for OpenZFS file systems via the S3 API and from S3-based services and applications. You can also use S3 Access Points to transfer data to and from your file system without the need to mount it—for example, to copy data into your file system from an S3 bucket owned by a partner or to export job results into another team's bucket. Previously, S3 Access Points for FSx didn't support server-side copies, so transferring your data meant downloading and then uploading each object from a server you run. Starting today, you can now transfer data server-side using S3's standard CopyObject and UploadPartCopy operations, reducing the time, cost, and effort needed to move data between S3 and FSx or between FSx file systems.

It has been revealed that this capability is available in all AWS Regions where S3 Access Points for FSx are available. You can copy data with the AWS CLI, AWS SDKs, or S3-compatible tools to move and copy data. To learn more, see the FSx for ONTAP and FSx for OpenZFS user guides, and visit the Amazon S3 Access Points page.
