How I make GNOME more MacOS-like – with free dock extensions

Since its early beginnings, GNOME has changed considerably. What was once a fairly standard desktop is now a minimalist’s dream come true. On the desktop, all you see is a top bar. Click the application or workspace overview, and you are then treated to the heart of the DE.

Also: My favorite GNOME-based Linux distros – for minimalists who like options.

But for some, that’s not efficient enough, especially for those coming from MacOS who are used to having that handy dock at the bottom where applications can be accessed. The good is that there are some outstanding docks you can add to the GNOME desktop to make it look and feel a bit more like MacOS.

Below are my favorite free GNOME docks, from which I’m sure you’ll find one that perfectly meets your needs.

It has been revealed that I’m starting with the newest of the docks, but it’s also my favorite. There are several reasons why Dhruva Dock is the best, but topping that list is the ease and sheer number of configurations. Like many docks on this list, Dhruva Dock is added as a GNOME Extension. Customizing Dhruva Dock couldn’t be any easier. If you have the Extensions app installed (which I highly recommend), you can access the Dhruva Dock settings from there; otherwise, you’ll see the settings icon appear on its GNOME Extensions page (linked above).

In the Dhruva Settings window, you can customize presets, the layout, panel, appearance, blur, behavior, and the music pill. With Dhruva Dock, you can configure things like animation smoothness, opacity, style (such as MacOS Dock, Windows 11 Taskbar, GNOME Classic+, Ubuntu Dock, and more), animations (there are some fun ones here), window previews, modules (such as shortcuts to specific directories), and much more.

It has been revealed that one feature of Dhruva Dock that I really appreciate is the ability to click an icon on the dock to minimize or bring back an application. Unlike other docks, this feature is enabled by default.

Dhruva Dock is, by far, the most customizable dock you’ll find for GNOME; that, along with its elegant looks, makes it the best option for most users.

Dash to Dock is the most popular dock for GNOME. This extension moves the favorites panel (which appears as a dock in the overview) to the desktop. Although Dash to Dock doesn’t have nearly as many customization options as Dhruva Dock, its simplicity makes it a winner. You install it and use it. That’s the gist of Dash to Dock. Of course, that’s not quite being fair to this popular extension. Dash to Dock does allow you to customize the position and size, launchers, behavior, and appearance. It takes little time to get Dash to Dock looking just how you want it (although without the elegance offered by Dhruva Dock).

In a recent development, one feature I really appreciate in Dash to Dock is the ability to show mounted network volumes. Since I regularly use SMB shares on my network, having quick access to them is a bonus. On top of that, you also get keyboard shortcuts to activate apps. The shortcuts are Super+(0-9) and each shortcut is associated with the apps as they are arranged on the dock, so Super+0 opens whatever is associated with the far-left icon on the dock (the Application Overview button is not included in this).

Recent findings suggest that one option I always suggest you enable is the “Click action” option in the Settings window of the extension. Go to the Behavior tab and click the “Click action” drop-down. From that list, select Minimize. Now, when you click an application icon in the dock, it will minimize. This is especially helpful because GNOME doesn’t include a minimize icon for windows (although you can add it with the command gsettings set org.gnome.desktop.wm.preferences button-layout “:minimize,maximize,close”, but who wants to do that?).

Simple Taskbar is actually a taskbar extension that can be customized to resemble a dock. Don’t be fooled by the name, as Simple Taskbar does have a decent amount of customizations, but the out-of-the-box experience is already quite good (once you switch the mode to either dock or MacOS Dock).

I really appreciate the smoothness of the animations in Simple Taskbar, which is on par with what you’ll experience on MacOS. You can customize the thickness, layout, position, theming, transparency and blur, borders, included items, clicking/scrolling/hovering actions, animations, locations, and more. You can also customize the scroll action, selecting from switch workplace, cycle windows, change volume, or do nothing. For me, the best scroll action is switch workspaces because it makes it very easy to move between them. You can also choose to show Simple Taskbar on all monitors or only the primary. I prefer to have it only on the primary and set it to never hide; that way, I have one monitor that always demonstrates the dock and one that never shows it.

Sources indicate that for modes, you can select between taskbar, dock, default GNOME panel, Windows XP, Windows 10, or MacOS Dock. Another really cool feature is the Bottom Hot Edge. When enabled, this feature will reveal the GNOME Overview when the pointer is pushed against the bottom edge of the screen. You can also change this to open the App Grid instead of the Overview.
