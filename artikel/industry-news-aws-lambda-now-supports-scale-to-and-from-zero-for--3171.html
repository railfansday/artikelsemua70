Industry News: AWS Lambda now supports scale to and from zero for Lambda Managed Instances

🌐 Source: Amazon • 📅 17 Nov 2026 • ⏱️ 1 min read (218 words, 📖 Standard)
💡 Key Takeaways
  • AWS Lambda now supports scale to and from zero for Event Functions running on Lambda Managed Instances (LMI).
  • Lambda Managed Instances lets you run Lambda functions on your Amazon EC2 instances while maintaining the operational simplicity of Lambda.
  • According to recent reports, this feature is available today in all AWS commercial Regions where Lambda Managed Instances is available.

AWS Lambda now supports scale to and from zero for Event Functions running on Lambda Managed Instances (LMI). Lambda automatically scales execution environments for your function to zero during idle periods and scales them back up when requests arrive, without requiring you to provision minimum capacity. This makes LMI cost-effective for intermittent workloads such as asynchronous processing, development, and test environments.

Lambda Managed Instances lets you run Lambda functions on your Amazon EC2 instances while maintaining the operational simplicity of Lambda. With Lambda Managed Instances, you can access specialized compute configurations and drive cost efficiency through EC2 pricing advantages, without managing infrastructure. Previously, customers needed to keep a minimum number of execution environments running even when there was no traffic. With this launch, Lambda scales execution environments for your function to zero after a period with no activity, and provisions them again when requests arrive. This improves cost efficiency for workloads with periods of no traffic.

According to recent reports, this feature is available today in all AWS commercial Regions where Lambda Managed Instances is available. To get started, set MinExecutionEnvironments to zero for your function using the Lambda console, AWS CLI, AWS SDKs, AWS CloudFormation, AWS SAM, or AWS CDK. To learn more, visit the AWS Lambda Developer Guide and AWS Lambda pricing.
