Recent findings suggest that ladybird is a brand upcoming web browser, written entirely from scratch. It’s not based on Chromium, Firefox, or Safari, and its aim is to be a complete, usable browser for the modern web.

Also: I’ve used nearly every browser out there, and these are my top 4.

On Monday, Ladybird president Andreas Kling announced that the browser was in Alpha: “Ladybird is a browser with a newly introduced engine. The engine is our own, built from the ground up, and not a fork. The browser around it is modest, but functional.”.

Recent findings suggest that kling made it clear that the Ladybird alpha channel is a rolling release and that the developers will be pushing out regular, automatic updates. Being a rolling release means that Ladybird will improve very quickly, and users will no longer have to build the browser each time something upcoming arrives. Once installed, the updates come automatically.

Industry observers note that ladybird uses a multi-process architecture for networking, image decoding, compositing, and media. Ladybird loads pages from different sites in separate renderer processes, each sandboxed from the host system, and image decoding and network connections are handled outside the renderer processes to make the browser better able to stop malicious content. The developers invite security researchers to report issues.

But Ladybird is more than a fresh web browser engine written from scratch; it’s a philosophy built on web standards, free from conflicts of interest, with no default search deals, crypto tokens, or other forms of monetization. Ladybird hearkens back to the days when web browsers were simply tools for end-consumers, and not the means to a corporate end.

Also: Too many tabs? Try these browsers with better tab management than Chrome.

Sources indicate that however, Ladybird does have sponsors, including Futo, Shopify, Cloudflare, and Proton VPN. It’s also open-source — you can check out the code on the official GitHub repository. Even with sponsors, Ladybird is independent — an independence backed by a two-clause BSD license.

In a recent development, but how does Ladybird perform? I installed it on Pop!_OS Linux to see how it compared to my usual browsers (Firefox and Vivaldi).

Let’s fly this coop and find out.

After a quick install (via the flatpak command flatpak install — user ‘https://flatpak.ladybird.org/ladybird.flatpakref‘) — I opened the browser and was greeted by what looked like a standard Chrome-ish UI.

Upon launch, I was able to select my search engine, layout, color, enable ad blocking, and enable automatic updates. I chose DuckDuckGo, switched to the “Everything in the sidebar” layout, selected purple as my color, enabled ad blocking, and enabled automatic updates. Once that was taken care of, I had a browser layout and look that better suited me.

According to recent reports, the first site I visited was ZDNET, and I found it rendered promptly and accurately. Scrolling was smooth, and internal links loaded without any challenges. I then walked through a trove of sites I usually visit to see if any of them caused problems. I actually found that Facebook performed considerably better on Ladybird than on Firefox, without any scrolling issues or rendering lag.

According to recent reports, what really took me by surprise was how easy Ladybird is to use. It’s just so straightforward, especially once you’ve selected the layout that suits your typical workflow. Nothing got in the way; using it was intuitive, and it performed every bit as well as the other browsers I tested it against.

The one issue I had with Ladybird was that its default behavior was to forget all open tabs upon closing. That was an easy fix (Settings > Startup and browsing > Restore previous windows and tabs).

Industry observers note that at first blush, the only thing I found missing in Ladybird was extensions (as there are none). Oddly enough, I don’t mind that, because it means there’s less bloat to slow it down. Yes, I miss Grammarly integration, but that’s pretty much it. If you, on the other hand, rely on extensions, you’ll want to hold off until Ladybird is out of alpha (in the hope that the developers add an extensions feature).

Also: I found the most private and secure way to browse the web.

Sources indicate that some users might open Settings > “Privacy and security” and think that Ladybird is missing quite a bit. If, however, you go to Content blocking, you’ll see that it lets you select filter lists to block ads, trackers, and more.

It might behoove the developers to move content blocking to the security/privacy section to avoid confusing users. Whether that happens or not, don’t be fooled; Ladybird does take security seriously.

After my testing concluded, I decided that I liked Ladybird enough to keep it around. Honestly, I liked it enough that I’d continue using it for certain tasks. No, I won’t be using it for productivity, but only because it’s in Alpha. I have a feeling that once Ladybird has reached a stable release, it might well become my default.
