AWS Security Hub Network Scanning now supports scanning Amazon Relational Database Service (Amazon RDS) database instances

🌐 Source: Amazon • 📅 16 Nov 2026 • ⏱️ 1 min read (243 words, 📖 Standard)

  • In a recent development, RDS scanning gives you more visibility into which resources in your environment are reachable from the internet.
  • Network Scanning probes your resources from the internet to detect reachability, beyond what security group rules and route tables suggest.

Recent findings suggest that AWS Security Hub Network Scanning now scans Amazon RDS DB instances to identify those that are reachable from the internet. Network Scanning automatically discovers existing and new RDS DB instances in your accounts and scans each instance that has Public Access configured. For each reachable port associated with a DB instance, Security Hub creates a finding with details about the instance and the reachable port.

In a recent development, RDS scanning gives you more visibility into which resources in your environment are reachable from the internet. You can then investigate and update their access settings as needed. RDS scanning is turned on automatically for all customers who already have Network Scanning enabled.

Network Scanning probes your resources from the internet to detect reachability, beyond what security group rules and route tables suggest. Security Hub Exposures then correlates these findings with other findings and resource configurations to assess broader risk.

Existing Security Hub customers can enable Network Scanning in individual accounts and Regions, or across an organization with a configuration policy. For new Security Hub customers, Network Scanning is on by default. Network Scanning is included with Security Hub Essentials at no additional cost in all AWS commercial and AWS GovCloud (US) Regions that support Security Hub. To learn more, see the AWS Security Hub User Guide and the AWS Security Hub product page. For the full list of Regions, see the AWS Regional Services List.
