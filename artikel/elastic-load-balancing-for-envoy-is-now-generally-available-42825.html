According to recent reports, today, AWS announces the general availability of ELB for Envoy, a new load balancer type in Elastic Load Balancing (ELB) that runs open-source Envoy proxies. Platform teams that run Envoy themselves own upgrades, security patching, and capacity across Availability Zones (AZs). ELB for Envoy takes on that work. Each load balancer runs its proxies on dedicated Amazon Elastic Compute Cloud (Amazon EC2) instances with hardware isolation from the AWS Nitro System, so a zero-day in Envoy stays contained to your load balancer. ELB for Envoy also monitors for security vulnerabilities (CVEs) and applies Envoy and operating system patches automatically, so you can focus on your applications instead of your proxy fleet.

According to recent reports, you can bring your existing Envoy configurations, extensions, and control planes as they are, and add AWS integrations such as AWS Certificate Manager (ACM) and AWS WAF with minimal configuration. If you run Envoy Gateway on Kubernetes, install the ELB for Envoy remote infrastructure provider alongside Envoy Gateway to move your proxies to ELB for Envoy without rewriting your Gateway API resources.

Industry observers note that you can add custom logic with WebAssembly, Lua scripting, or external processing. ELB for Envoy runs inside your VPC, integrates with Amazon Virtual Private Cloud (Amazon VPC) security groups, and supports VPC encryption. It's well suited to workloads that need Envoy's extensibility, such as custom authentication, request transformation, or advanced traffic routing, along with Kubernetes ingress and migrations from self-managed Envoy.

Sources indicate that at general availability, ELB for Envoy is available in 14 AWS Regions: US East (N. Virginia), US East (Ohio), US West (Oregon), Europe (Ireland), Europe (Frankfurt), Europe (Stockholm), Europe (Spain), Asia Pacific (Sydney), Asia Pacific (Hong Kong), Asia Pacific (Tokyo), Asia Pacific (Singapore), Asia Pacific (Mumbai), Asia Pacific (Malaysia), and Asia Pacific (Thailand). To learn more, visit the ELB for Envoy product page, ELB pricing page, and documentation. To get started, visit the AWS Management Console.
