And hit $36M ARR in just 45 days with a 20-person team.

Genspark⁠(opens in a latest window) is the company behind Super Agent, a no-code, customizable AI agent that helps users automate real-world tasks like making a phone call, generating a presentation, or turning a recipe into a short video.

It has been revealed that super Agent uses OpenAI multimodal models and Realtime API to enable tasks across text, image, and voice, allowing people to automate complex workflows with simple prompts, no coding required. The system took off: in just 45 days, Super Agent reached $36M in ARR, driven by strong user demand.

Genspark initially introduced as an AI search engine designed to help consumers and professionals synthesize and structure information. By late 2024 user behavior started shifting. Users didn’t just want answers. They wanted outcomes. Instead of “summarize this market,” they were asking for pitch decks, video scripts, and follow-up emails. At the same time, model capabilities were rapidly expanding. Longer context windows, stronger reasoning, and upcoming multimodal APIs made it increasingly possible to automate entire workflows, not just retrieve information.

That shift in user demand and model readiness led the team to make a bold move: in April 2025, Genspark pivoted away from search and fully embraced agentic AI.

In a recent development, in April 2025, Genspark launched Super Agent: a fully autonomous, no-code assistant that can make phone calls, design slides, generate videos, and more. Under the hood, the platform orchestrates nine specialized large language models and more than 80 integrated tools, dynamically assigning each task to the best-suited component.

It has been revealed that openAI models are central to this system. GPT‑4.1 handles research and structured outputs with improved instruction following and a 1M-token context window, allowing agents to process long documents in full without truncation. Strict JSON output is designed to ensure reliably structured responses for downstream tools, while automatic prompt caching reduces latency and API costs which is especially valuable in multi-step workflows. For image generation, the platform uses the GPT‑image‑1 model via the OpenAI API.

Because the system is fully no-code, consumers don’t need to think about any of that. They describe what they want, “call my dentist,” “summarize this report,” “make me a slide deck”, and Super Agent handles the rest.

One of Super Agent’s most talked about features is Call For Me, an AI that makes real phone calls for you, and actually holds a conversation. No scripts. No clunky transfers. Whether booking a reservation or rescheduling a delivery, the agent uses the OpenAI Realtime API and speech-to-speech capabilities to handle the conversation naturally and with real-time fluency.

In a recent development, A dual-layer system powers the interaction: the Realtime API manages the live dialogue, while a shadow model monitors and guides the interaction via message queue. The result is fast, coherent back-and-forth, even when the call includes hold music or ambiguous human responses. In Japan, one use case went viral: owners asking the agent to handle resignation calls to their employers. It’s the kind of deeply human interaction most people don’t expect an AI agent to handle.

Beyond phone calls, customers rely on Super Agent to create personalized content. Ask for a vaporwave-style pitch deck, and the agent drafts the slides, generates stylized cover images with GPT‑image‑1, and compiles the final deck. For video, it can write a scene-by-scene script, generate the images, and assemble an Instagram-ready short.

Recent findings suggest that these use cases are possible by OpenAI multimodal capabilities, Genspark’s execution speed, and their close collaboration with the OpenAI startups team. Genspark met regularly with OpenAI solutions architects to share best practices, fine-tune workflows, and optimize model performance. They were among the first to launch voice experiences with the Realtime API, and continue to contribute feedback that helps drive model improvements.

In a recent development, “We chose OpenAI not just for model performance across modalities, but for developer experience,” claims Zhu. “The OpenAI API design helped us move promptly, shipping, debugging, and scaling without bottlenecks.”.

In just over a month after launching Super Agent, Genspark has:.

Grown to $36M ARR in just 45 days.

Shipped eight major agent features in 70 days.

All of this was achieved with a 20-person team and no paid advertising. That growth was entirely organic, driven by product virality and word-of-mouth. Much of Super Agent’s appeal comes from its accessibility. People don’t have to build workflows or configure settings. They just say what they need and the agent handles the rest.

Next, Genspark is expanding into upcoming categories where autonomous agents can drive even more value, like an AI browser that acts on all of the content you’re browsing and AI docs for generating format-rich documents. OpenAI APIs remain core to how the team builds fast and ships faster.

In a recent development, “We built Genspark to be more than a chat interface, it’s an all-in-one AI workspace,” says Zhu. “And with OpenAI APIs, we were able to make that real in record time.”.
