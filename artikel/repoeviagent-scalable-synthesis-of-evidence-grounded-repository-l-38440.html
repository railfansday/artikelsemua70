RepoEviAgent: Scalable Synthesis of Evidence-Grounded Repository-Level Question Answering Tasks

🌐 Source: Arxiv • 📅 26 Nov 2026 • ⏱️ 1 min read (156 words, 📖 Standard)

According to recent reports, arXiv:2611.31873v1 Announce Type: newly introduced Abstract: Real-world software engineering (SWE) tasks require agents to understand repository structures, cross-module dependencies, and runtime behaviors, posing significant challenges for constructing high-quality training and evaluation data. To address this, we propose RepoEviAgent, a scalable SWE data construction framework that integrates quality-aware data curation and role-specialized multi-agent task synthesis. Starting from 8,477 open-source repositories and approximately 2.48 million pull request records, we employ semantic alignment, complexity constraints, and multidimensional quality assessment to identify valuable SWE data. We further develop a sandbox-based multi-agent framework that integrates automated environment construction, execution validation, repository exploration, and evidence-grounded Q&A synthesis. Based on this framework, we construct RepoEviQA, a benchmark for Repository-Level Evidence-Grounded Question Answering, comprising 334 tasks across five programming languages and diverse SWE categories, with rigorous rubric-based evaluation. We evaluate five frontier coding models on RepoEviQA, revealing substantial performance differences across task categories and programming languages.
