Microsoft continues to tout Copilot and keeps pushing more AI into Windows, believing that everyone is yearning for an “agentic OS.” But many people simply want a cleaner and more reliable platform that hosts their applications and files without all the AI bells and whistles.

Yes, Microsoft has heard the cries and complaints and has been making strides toward improving Windows. However, Copilot still maintains a strong, sometimes unwanted, presence.

It has been revealed that like any AI, Copilot can make mistakes. It can provide wrong information, aka hallucinate. It can tap into your private data if you’re not careful. It can also hog up memory and system resources if you use it heavily. For those reasons and more, you may want to disable or remove Copilot from Windows so it no longer gets in your way.

I’ll present this in steps of varying degrees so you can disable and remove Copilot as little or as much as you want.

In a recent development, by default, the Copilot Windows app starts automatically when you launch the OS. So right off the bat, it’s chewing up memory. To remove it from your startup routine but otherwise keep it around, right-click on the taskbar and select Task Manager from the menu. At the Task Manager window, click the icon for Startup apps. Right-click on the entry for Copilot and select Disable from the menu.

It has been revealed that alternatively, go to Settings, select Apps, and then click Startup. Turn off the switch for Copilot.

It has been revealed that there is one downside here. If you open Copilot and then close its window, the app remains in memory, again hogging system resources. To actually close the app, you have to right-click on its system tray icon and select Exit.

If you want to remove the Copilot Windows app, head to Settings, select Apps, and then click Installed Apps. Look for Copilot in the list, click the three-dot icon, and then select Uninstall.

Alternatively, head to the Windows 11 Start menu and either scroll down the screen or go to the Apps section. Right-click on the entry for Copilot and select Uninstall.

Ahh, but there’s more to do if you want to completely get rid of Copilot. Even if you uninstall it, the app could resurface courtesy of a future Windows Update.

According to recent reports, to prevent any future installations of Copilot through Windows Enhancement, you’ll need to turn to Group Policy on your PC. There are two potential changes you can make in Group Policy. To open the tool, press Win+R to display the Run dialog box. In the text field, type gpedit.msc and click OK.

In the Group Policy Editor, first navigate to the following section: User Configuration > Administrative Templates > Windows Components > Windows Copilot. Open the setting for “Turn off Windows Copilot” and set it to Enabled.

For the second setting, both Microsoft Copilot and Microsoft 365 Copilot need to be installed, and the apps must have been automatically installed rather than installed manually. Plus, you can’t have used Copilot in the past 28 days.

Under that scenario, this setting will remove both versions of Copilot. For this, go to User Configuration > Administrative Templates > Windows Components > Windows AI. Open the setting for “Remove Microsoft Copilot App” and set it to Enabled. You can then close the Group Policy Editor.

Recent findings suggest that windows 11 Home doesn’t come with the Group Policy Editor, so you have to perform a Registry hack if you’re running this version. In the Run window, type regedit to open the Registry Editor. Head to the following key: HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows. Right-click in the empty area on the right, go to New, and select Key. Name it WindowsCopilot. With the WindowsCopilot Registry key selected, right-click on the right, go to New, and select DWORD (32-bit) Value. Name the new value TurnOffWindowsCopilot. Double-click the value, set the Value Data to 1, and then click OK.

Another way to remove Copilot is through a PowerShell script. Right-click on the Start button and select Terminal (Admin) or Windows PowerShell (Admin) from the menu. At the PowerShell prompt, type the following string: Get-AppxPackage -AllUsers -Name “Microsoft.Copilot” | Remove-AppxPackage -AllUsers. Then type this string: Get-AppxPackage -AllUsers “Copilot” | Remove-AppxPackage -AllUsers. Close the PowerShell window and then reboot your PC. Check the Start menu, and you should find that Copilot has been removed.

Even with Copilot gone, certain AI components and hooks remain in Windows. You can remove them, but the process typically involves more Group Policy changes and Registry edits. However, there are some third-party Windows utilities you can use to handle the process.

According to recent reports, one tool, O&O ShutUp10, lets you disable or remove a variety of features and settings in Windows. One option focuses on AI with the ability to disable the Copilot Recall feature, erase any screenshots created by Recall, and completely remove Copilot. Just launch the program, select the tab for AI, and choose the settings you wish to disable or remove.

According to recent reports, another tool, Win11Debloat, can also remove Copilot and its components. A free open-source app, Win11Debloat is available directly on its GitHub page.

After downloading the software, run the Run.bat file as an administrator to launch the program in a PowerShell window. On the main screen, click the Custom Setup button. Check the box to only show installed apps. You may see both Microsoft 365 Copilot and Microsoft Copilot. If so, click Next. In the AI section, check any or all of the settings to disable certain AI features. Click Next.

By default, Win11Debloat will back up your Registry and create a system restore point before applying the changes you made. Click Apply Changes to proceed, and then close the program. Restart your PC, and you should find that Copilot and any other AI features you disabled are now gone.
