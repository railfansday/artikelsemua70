AWS Quick now supports group assignments for custom permissions and limit profiles

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (225 words, 📖 Standard)

AWS Quick now supports assignments for custom permissions and limit profiles to groups from your enterprise identity provider (IdP). Administrators can now apply feature restrictions and per-user resource limits to IdP groups, in addition to the existing user, role, and account assignments. Organizations can align governance with their enterprise identity structure without maintaining assignments for individual people. Administrators manage user, account or group assignments in the Quick administration console or through upcoming policy assignment APIs. For example, an organization can assign its finance group a custom permissions profile that blocks members from creating agents, or apply Deny by Default so that, within selected feature categories, the group can use only capabilities an administrator explicitly allows. Administrators can also assign a limit profile to a group to set each member’s index capacity and agent hours. Quick enforces these limits automatically as users consume resources. When group-level assignments apply to a user who belongs to multiple groups, Quick resolves overlapping assignments as follows: for custom permissions, a capability denied by any group stays denied, and for limit profiles, the user receives the highest value for each limit type across those groups. Group assignments are available in Quick for Professional and Enterprise aims. For feature availability by AWS Region, see AWS Quick Regions. To learn more, see the custom permissions and limit profiles documentation.
