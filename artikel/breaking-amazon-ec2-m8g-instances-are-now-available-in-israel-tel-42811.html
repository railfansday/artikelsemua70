Breaking: Amazon EC2 M8g instances are now available in Israel (Tel Aviv)

🌐 Source: Amazon • 📅 25 Nov 2026 • ⏱️ 1 min read (180 words, 📖 Standard)

It has been revealed that starting today, Amazon Elastic Compute Cloud (Amazon EC2) M8g instances are available in the Israel (Tel Aviv) region. These instances are powered by AWS Graviton4 processors and deliver up to 30% better performance compared to AWS Graviton3-based instances. Amazon EC2 M8g instances are built for general-purpose workloads, such as application servers, microservices, gaming servers, midsize data stores, and caching fleets.M8g instances are up to 40% faster for databases, up to 30% faster for web applications, and up to 45% faster for large Java applications than AWS Graviton3-based M7g instances. These instances are built on the AWS Nitro System, which offloads CPU virtualization, storage, and networking functions to dedicated hardware and software to enhance the performance and security of your workloads. M8g instances offer larger instance sizes with up to 3x more vCPUs and memory than Graviton3-based M7g instances. M8g instances are available for purchase in this region via Savings Aims, On-Demand, Spot Instances, Dedicated Instances, or Dedicated Hosts. Level up your compute with AWS Graviton and get started with M8g today.
