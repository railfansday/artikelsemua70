Tech Report: Amazon SES now supports higher limits for email identities, tenants, and configuration sets

🌐 Source: Amazon • 📅 11 Nov 2026 • ⏱️ 1 min read (182 words, 📖 Standard)
💡 Key Takeaways
  • It has been revealed that amazon Simple Email Service (Amazon SES) now supports higher limits for email identities, tenants, and configuration sets.
  • Industry observers note that customers running multi-tenant workloads often create a separate email identity, tenant, or configuration set for each customer, brand, or AI agent they serve.
  • Higher limits for email identities, tenants, and configuration sets are available in all AWS Regions where Amazon SES is available.

It has been revealed that amazon Simple Email Service (Amazon SES) now supports higher limits for email identities, tenants, and configuration sets. You can view your current usage against each limit and request increases in the AWS Service Quotas console. A single account can now keep pace with your growth, so you no longer need to split email workloads across several accounts to stay within per-account limits.

Industry observers note that customers running multi-tenant workloads often create a separate email identity, tenant, or configuration set for each customer, brand, or AI agent they serve. As you add more customers, brands, and AI agents, these resources can multiply promptly, and higher limits let all of these workloads grow in one account. To help you manage larger accounts, you can now also search these resources by name or status.

Higher limits for email identities, tenants, and configuration sets are available in all AWS Regions where Amazon SES is available.

To learn more, see Service quotas in Amazon SES in the Amazon SES Developer Guide and the Amazon SES product page.
