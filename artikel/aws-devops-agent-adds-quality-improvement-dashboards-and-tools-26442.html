AWS DevOps Agent adds quality improvement dashboards and tools

AWS DevOps Agent now gives you dashboards and tools to enable you to understand and improve the quality of your AWS DevOps Agent instances in your environments.

With this launch AWS DevOps Agent now helps you measure the quality of its work. Latest quality and latency dashboards track the results. For investigations, you see how often AWS DevOps Agent finds the root cause, how long it takes, and where it lacked context. For mitigations, you see the time to the first strategy and how your operators rated each plan. Trend views show whether quality improves over time. A new grader agent rates each investigation. Its dashboard compares those ratings with your operators' ratings, so you can focus on the cases where they disagree. Both grader agent and human ratings become memories that improve the quality of future task runs.

Once you understand the quality and performance of your instance of AWS DevOps Agent, you can improve it by configuring or modifying its skills, memories, and tools. To ensure that changes improve your instance, AWS DevOps Agent now provides a replay capability that lets you test changes before you rely on them. You can replay a past investigation to see whether a change to a skill, memory, or instruction makes AWS DevOps better. Start a replay from any past investigation, and note what you changed. The replay uses your current configuration on live data, without changing anything. When it finishes, compare it side by side with the original: grader score, duration, root cause, and the tools and skills each run used. If the comparison reveals a gap, adjust your change and replay again.
