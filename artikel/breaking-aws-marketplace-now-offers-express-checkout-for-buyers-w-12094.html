Breaking: AWS Marketplace now offers Express Checkout for buyers without an AWS account

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Today, AWS introduces AWS Marketplace Express Checkout, a simpler way for businesses that don't have an existing AWS account to buy software from established vendors in AWS Marketplace.

Industry observers note that express Checkout is built for businesses that don't use AWS today and just want to buy software. With no cloud setup required, buyers sign in with an email address or a social login, pay with a credit or debit card, and check out in a few steps. Businesses that buy multiple applications this way can manage all of their Express Checkout subscriptions in one place, without a separate billing login for each vendor. From there, they can revision their card, download invoices, or cancel a subscription themselves.

According to recent reports, for sellers, Express Checkout opens a new segment of self-serve business buyers, using the same listing and AWS Marketplace integration they use today. Sellers with an eligible public SaaS listing can request to add their product to the Express Checkout catalog.

According to recent reports, express Checkout is available for eligible SaaS products to buyers in the United States and Canada. Businesses that already use AWS can continue to buy in AWS Marketplace with their AWS account.

It has been revealed that to get started, visit the AWS Marketplace Express Checkout page. To learn more, see the  AWS Marketplace Buyer Guide and the  AWS Marketplace Seller Guide.
