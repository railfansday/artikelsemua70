📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Recent findings suggest that AWS Device Farm, a service for testing mobile and web apps, now offers Device Connect. With Device Connect, you and AI agents can use remote Android devices from your local machine in an IDE, terminal, or development environment of your choice, as if it were plugged into your laptop. You can attach a debugger, profile performance, preview builds, run ADB (Android Debug Bridge) commands, and interact manually with the devices. You also get live video along with device and test logs. Tools and test frameworks that work with ADB locally now run on a real device that Device Farm manages for you.

Previously, you used Device Farm devices manually in a web browser or for automated tests through APIs. You couldn't reach them from your local tools, such as Android Studio or a terminal. Device Connect closes that gap by connecting your local machine to a device hosted in AWS. Your existing ADB-based workflows run unchanged.

According to recent reports, to get started, install the Device Connect client from GitHub, create a remote access session on Device Farm, and attach to the session's device with the 'devicefarm-connect' command. Device Connect supports Android OS versions nine and later. The client runs on macOS, Linux, and Windows with no additional cost. Device usage is billed at standard Device Farm rates.

Device Connect is available in the US West (Oregon) AWS Region.

To learn more, see the AWS Device Farm Developer Guide.
