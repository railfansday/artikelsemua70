AWS Lambda adds support for GPU instances on Lambda Managed Instances

🌐 Source: Amazon • 📅 18 Nov 2026 • ⏱️ 2 min read (351 words, 📖 Standard)
💡 Key Takeaways
  • AWS Lambda now supports GPU-accelerated Event Functions on Lambda Managed Instances using EC2 G-series instances.
  • According to recent reports, running GPU workloads today requires customers to provision hardware, manage driver and framework dependencies, and build custom scaling and capacity management.
  • Recent findings suggest that GPU-accelerated Event Functions on Lambda Managed Instances is available in all AWS Commercial Regions where Lambda Managed Instances and EC2 G-series instances are available.

AWS Lambda now supports GPU-accelerated Event Functions on Lambda Managed Instances using EC2 G-series instances. You can now run GPU-accelerated workloads including AI inference, media processing, 3D rendering, scientific computing, and financial simulations on Lambda without managing GPU drivers, frameworks, or scaling. Lambda runs multiple invocations concurrently in each execution environment and scales responsively based on GPU utilization, CPU utilization, and concurrency to keep your GPUs busy and reduce costs. GPU-accelerated functions integrate with the same 200+ AWS event sources as other Event Functions, so you can add GPU compute as another step in your serverless application.

According to recent reports, running GPU workloads today requires customers to provision hardware, manage driver and framework dependencies, and build custom scaling and capacity management. With this launch, you can go from code to a running GPU workload in minutes. Lambda provides GPU base images preconfigured with frameworks such as vLLM, SGLang, and PyTorch. You can run workloads with large artifacts using container images and NVMe ephemeral storage of up to 32 GB each. To reduce startup time, Lambda supports Seekable OCI (SOCI) lazy loading and streaming artifacts directly from Amazon S3. For resilience, you can select G-series instance types from multiple generations in the allowed instance types for your capacity provider. Lambda provisions instances from the newest generation that meets your function requirements and falls back to older generations when capacity is unavailable.

Recent findings suggest that GPU-accelerated Event Functions on Lambda Managed Instances is available in all AWS Commercial Regions where Lambda Managed Instances and EC2 G-series instances are available. You can configure GPU-accelerated functions using the AWS Console, AWS CLI, AWS SDKs, AWS CloudFormation, AWS CDK, or AWS SAM. You can also use this feature through coding assistants such as Kiro, Claude Code, or Codex by installing the Lambda Managed Instances skill from the Agent Toolkit for AWS. You pay the EC2 On-Demand price (Savings Plans and Reserved Instances apply) for your instance, plus a 9.75% Lambda management fee and $0.20 per million requests. To learn more, visit the AWS Lambda Developer Guide and AWS Lambda Pricing.
