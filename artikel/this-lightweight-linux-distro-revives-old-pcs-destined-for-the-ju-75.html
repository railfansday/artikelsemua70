Recent findings suggest that there are more Linux distributions than you can imagine. Distributions for average desktop usage, AI, multimedia, number crunching, massive data, servers, and everything in between. There are also Linux distributions created specifically for older or slower hardware, which are typically labeled “lightweight” distributions. They might include specialized kernels, apps that aren’t resource-intensive, and desktop environments that are best suited for lesser-powered machines.

Of the list of lightweight Linux distributions that I have considered to be solid options, the following distros tend to always land somewhere in my top five:.

Recent findings suggest that bodhi Linux has been one of my favorite lightweight Linux distributions for a long time, primarily because it offers the Moksha desktop (which is a fork of Enlightenment) that is equal parts efficiency and beauty. Thanks to Moksha, Bodhi Linux is a great option for older hardware. The only concern some might have with Bodhi is that the Moksha desktop is quite different from anything they’ve ever used.

According to recent reports, linux Lite uses a customized Xfce desktop and ships with a decent collection of apps, so you can be productive right out of the box. You’ll find Chrome, LibreOffice (including Base, to create databases), GIMP, Photo Manager, Deja Dup Backups, VLC media player, a USB image writer, an onscreen keyboard, Timeshift (for restore points), and more.

Xubuntu is essentially Ubuntu with the Xfce desktop. Because it uses Xfce, it’s highly customizable. And like Linux Lite, Xubuntu includes all the software you need to get going, such as LibreOffice (office suite), Firefox (web browser), Thunderbird (email client), Transmission (torrent client), Catfish (file search tool), GIMP (image editor), Rhythmbox (music player), Parole Media Player, and Atril Document Viewer.

It has been revealed that other than Bodhi Linux, the other two options might come across as looking a bit outdated; that’s because Xfce focuses more on speed and customization than aesthetics. Although that doesn’t mean any of the above are less usable, if you prefer your desktop operating system on the more modern side of things, you might find yourself rather disappointed with the above. That’s why, when I got my first peek at the oddly named XXRI-OS-LITE, I was immediately excited.

Industry observers note that there’s now another lightweight Linux option, but one that doesn’t shrug off aesthetics. If you’ve read me long enough, you know that the way a Linux desktop looks is just as notable as how it functions (to me).

As the name implies, XXRI-OS-LITE is a lightweight Linux distribution that is perfectly capable of reviving your older hardware. But this distribution goes a bit further than most lightweight distros by also delivering a modern desktop that doesn’t depend on the terminal window and offers zero complexity. XXRI-OS-LITE isn’t just lightweight; it’s beautiful and easy to use.

It has been revealed that XXRI-OS-LITE can be run on a system with very low resources. The minimum requirements are a Pentium II or K6-2, 256 MB of RAM, and 700 MB of storage.

If that sounds like you, XXRI-OS-LITE might be right up your alley.

Industry observers note that the XXRI-OS desktop is comprised of a dock, a desktop menu, and a system tray, all of which come together to create a nice, macOS-inspired desktop. If you click the desktop menu, you’ll see the few apps that are installed by default, which include a control center, power menu, terminal, a text editor, a web browser, a file manager, a media player, a settings app, and an app store. That’s it.

Recent findings suggest that when you click to open an app, the first thing you’ll notice is how fast it opens…like instantly. Lightweight distributions tend to be fast, but not like this. This feels like COSMIC Desktop (from System76) running on a Thelio (which is a beast of a desktop). This is fast in a way you don’t usually see.

XXRI-OS-LITE is based on Tiny Core Linux and is the lightweight version of XXRI-OS (which is still under development). At the same time, XXRI-OS-LITE is also early in the development process, which means there will be problems. The difference between the two (other than one being a lightweight distribution and the other not) is that the LITE version ships with a bare minimum of apps. Under normal circumstances, that would be fine because there’s a GUI app store.

I did run into a rather interesting issue. Even though I could get online with the OS (both in the browser and from the command line), the App Store refused to connect. I wrote this off as an early dev issue, but after a bit of digging around, I started thinking that maybe it was the repository being offline, so I waited a few hours and checked again. Same problem. I then hopped onto the XXRI-OS-LITE Discord server and discovered that this is a known issue.

Recent findings suggest that apparently, the App Store works fine over Wi-Fi, but not Ethernet. Because this problem is known, I’m sure it’ll be resolved soon. In the meantime, I decided to give an AppImage a try to see how well it would run.

It has been revealed that I uploaded my Quillwriter app as an AppImage, and the OS automatically detected that it should be executable and asked me if I wanted to give it the necessary permissions and then integrate it into the system (which means adding it to the desktop menu). After that, the app opened very quickly (as fast as it does on my MacBook M1) and functioned exactly as expected.

It has been revealed that even with the App Store issue, XXRI-OS-LITE indicates a lot of promise, so much so that if the developers can keep the project going, I could see this distribution jumping ahead of the current crop of top distros in its class. And with an aesthetic that makes XXRI-OS-LITE look more like a serious desktop distribution, the sky’s the limit.

Recent findings suggest that before you jump on the XXRI-OS-LITE bandwagon, know that, as I mentioned before, it’s early in the development process, which means it has a ways to go before it’s ready for the masses. Even so, this Linux distro is off to a great start; it’s fast, beautiful, and easy, it runs on hardware that most would have considered tossing into a junk pile, and it proves that a lightweight Linux distribution doesn’t have to look and feel as if it teleported from the early 2000s.

Recent findings suggest that would I recommend it over the other three lightweight distros I mentioned earlier? Not at the moment, but once the developers resolve the App Store concern, that could very quickly change.

It has been revealed that give XXRI-OS-LITE a try and see what it’s all about. Just remember, although the current version is 2.7, it feels a bit younger than that. Even so, it’s a fantastic start to a promising lightweight Linux distribution.

I’m very excited for what XXRI-OS-LITE can bring to the table.
