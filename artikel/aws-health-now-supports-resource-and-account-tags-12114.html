AWS Health now supports resource and account tags

🌐 Source: Amazon • 📅 19 Nov 2026 • ⏱️ 1 min read (242 words, 📖 Standard)

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Sources indicate that AWS Health now supports resource and account tags in Health events. This new capability enables you to enrich Health events with resource tags and account tags, providing additional context to help you manage and respond to events more effectively.

Industry observers note that with this feature, you can now view resource tags directly within Health events for supported AWS services. This allows you to quickly identify which resources are affected and understand their business context without needing to navigate to individual service consoles. Additionally, account-level tags help you categorize and filter events across your organization, making it easier to route notifications and automate responses based on your organizational structure.

In a recent development, this enhancement is particularly valuable for organizations managing large-scale AWS deployments. By leveraging tags in Health events, you can streamline incident response workflows, improve cost allocation tracking for health-related events, and enable more granular event filtering in AWS Health Dashboard and AWS Health API responses.

According to recent reports, the feature integrates seamlessly with Amazon EventBridge, allowing you to create event-driven automation that responds to tagged resources and accounts. This enables sophisticated routing and handling of Health events based on tag values, supporting use cases such as automatically creating tickets in your IT service management system or sending targeted notifications to specific teams.

To enable tag enrichment, visit the AWS Health Dashboard or view the AWS Health User Guide for more information.
