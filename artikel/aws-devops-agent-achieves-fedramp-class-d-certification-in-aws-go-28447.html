AWS DevOps Agent achieves FedRAMP Class D Certification in AWS GovCloud (US-West)

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (145 words, ⚡ Quick Read)

AWS DevOps Agent is now certified at the Federal Risk and Authorization Management (FedRAMP) Class D level in AWS GovCloud (US). AWS DevOps Agent is your always-available operations teammate that resolves and proactively prevents incidents, optimizes application reliability and performance, and handles on-demand SRE tasks across AWS, multicloud, and on-prem environments.

Cloud Service Providers achieve and maintain FedRAMP Certification by meeting NIST 800-53 Rev 5 controls, undergoing annual independent assessment by a FedRAMP Recognized Independent Assessment Service, performing continuous monitoring and vulnerability management, publishing quarterly Ongoing Certification Reports, and issuing Significant Change Notifications to agencies for material changes to any AWS cloud service offerings the agency uses.

Recent findings suggest that to learn more about AWS DevOps Agent, read the launch blog and see getting started. For information on FedRAMP Certification updates, including Significant Change Notifications, visit the FedRAMP Compliance FAQ.
