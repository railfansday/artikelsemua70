AWS CDK Blocks reaches general availability

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (216 words, 📖 Standard)

  • CDK Blocks has no additional service fee, and you pay only for AWS resources when you deploy to AWS.

Recent findings suggest that AWS Cloud Development Kit (AWS CDK) Blocks, known as AWS Blocks in preview, is now generally available. It is an expansion of the CDK that simplifies building production-grade applications on AWS, by providing production-ready building blocks for common app features, such as data storage and processing, background jobs, and building AI agents.

According to recent reports, CDK Blocks build upon CDK constructs. CDK constructs are reusable pieces of code that define AWS infrastructure, such as a database or a storage bucket. CDK Blocks packages a CDK construct along with the connecting code applications need to use that infrastructure, incorporating AWS service-specific best practices, such as safe retries, dead-letter routing and partial-batch failures, and a local testing setup, reducing the code and configuration you need to write and maintain. It also enables you to compose and share your own custom components that incorporate your organization's requirements, helping teams build production ready applications faster.

CDK Blocks is available to use in all regions.

CDK Blocks has no additional service fee, and you pay only for AWS resources when you deploy to AWS. Its source code is published under the Apache License 2.0. To get started, see the CDK Blocks documentation, or view the source in the CDK Blocks GitHub repository.
