How I remove AI, ads, and bloatware from Windows 11 fast – with a free tool

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

In a recent development, microsoft saddles Windows 11 with hefty doses of two potential annoyances — AI and advertisements. The AI features include not just the Copilot app but AI in Notepad and Paint, Recall on Copilot+ PCs, and AI in Edge. As for ads, those typically come in the form of suggestions, tips, and promotions designed to tout other Microsoft products and services.

Sources indicate that you can try to ignore many of these, but they still get in your face. You can attempt to manually disable them, but that process can be challenging. Instead, I use a free third-party utility called Bloatynosy. This simple tool can deactivate a variety of annoyances and bloatware in Windows 11 across a range of categories.

Also: How to remove Copilot AI from Windows 11 completely – in 6 steps.

One category covers AI, another covers ads, a third focuses on privacy, and a fourth on installed apps. There are also categories for File Explorer, the taskbar, and Windows Patch. You’re able to explore each category to see the settings that can be removed or disabled.

You can also run a check of your PC to see which features and settings are installed and active on your system. From there, just select the elements you want to eliminate, and the program will give them the heave-ho.

Now, here’s how you can use Bloatynosy to debloat your Windows 11 PC.

Bloatynosy is accessible through its GitHub page. Read the page to get the latest details on the program, and then click the button showing the release number. On the next page, you can choose between two variations of Bloatynosy. One is a plain version, while the other includes a Microsoft .NET 11 desktop runtime to spruce up the appearance of the software. I’d go with the .NET variation.

It has been revealed that extract the downloaded ZIP file. Dig through the resulting folders until you see the Bloatynosy.exe file. Right-click that file and run it as an administrator to launch the program; no installation required except for the .NET runtime if that component isn’t installed. If Microsoft Defender’s Smart Screen tries to prevent the app from opening, click the More info link and select the Run anyway button.

In a recent development, the home screen for Bloatynosy displays all the categories for the different settings you may want to disable or remove. But your first task should be to check your PC to see which annoying elements are installed on your system. Click the Check PC button in the lower-right corner to start the scan.

After the PC check has finished, Bloatynosy shows you all the settings you can change or uninstall. Under AI, you may find settings to disable Copilot on the taskbar, disable the AI features in Edge, disable Recall, disable the AI features in Notepad and Paint, and remove Copilot entirely. Under ads, you’ll likely see options to disable Lock screen ads, disable Start menu ads, disable tailored experiences, disable tips and suggestions, and disable personalized ads.

According to recent reports, there are other helpful settings across other categories. You can align the Start button to the left, turn off the prompt to set Edge as the default browser, disable the Edge sign-in and first run experience (two settings I find particularly annoying), enable Dark mode, reduce the diagnostic data collected by Microsoft, and hide the Task View button on the taskbar.

It has been revealed that certain settings are checked by default, but you can opt to check or uncheck them all or just manually check specific ones. After you’ve confirmed or made your selections, click Apply if you want to run them.

The results of the PC scan don’t display the settings in any specific order. For that reason, you might prefer to view and address them per category. Click the Home button to return to the Home screen. Click the Details button for any category you wish to explore. You can then select or deselect specific settings for that category. Click the Apply button to make those changes.

Industry observers note that the screen then indicates how many settings were changed based on what you selected. It also notifies you if you need to restart File Explorer or Windows itself. After rebooting Windows, sign back in and reopen the program. Check the features and settings you removed or disabled to confirm that they’re gone.

Recent findings suggest that what if you disable a setting and then want it back? No problem. Bloatynosy will restore it for you. In the program, run the PC check again, then return to a category where settings were changed. The modified settings will be grayed out. Select the ones you wish to reset and then click the Restore button. Those settings are restored to their previous values.

Recent findings suggest that bloatynosy offers other options worth exploring. Right-click on a specific entry, and you can request more details about it, change just that one setting, select or deselect all the settings, or tell the program to ignore that entry in the future.

Finally, you’re able to adjust certain settings for the software. Click the Settings button at the top. Here, you can turn Dark mode on or off, update the catalog of settings, and enable AI explanations. For that last option, you then must select an AI provider such as Grok, OpenAI, or Anthropic. You then have to request and enter an API key. After that, right-clicking an entry and requesting details on it lets you request an AI description of it.

Overall, Bloatynosy does an effective job of ridding Windows of bloatware and other annoyances. The program is simple and user-friendly, and I highly recommend it.
