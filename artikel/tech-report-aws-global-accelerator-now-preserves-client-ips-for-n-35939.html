Tech Report: AWS Global Accelerator now preserves client IPs for NLBs with TLS listeners

🌐 Source: Amazon • 📅 23 Nov 2026 • ⏱️ 1 min read (255 words, 📖 Standard)
💡 Key Takeaways
  • Sources indicate that AWS Global Accelerator now preserves the client IP address for traffic sent to Network Load Balancer (NLB) endpoints with TLS listeners.
  • Previously, you couldn't add an NLB with a TLS listener to an accelerator that had client IP address preservation enabled.
  • Recent findings suggest that to enable this feature, add an NLB with a TLS listener as an endpoint to an accelerator with client IP address preservation setting turned on, the same way you add any NLB.

Sources indicate that AWS Global Accelerator now preserves the client IP address for traffic sent to Network Load Balancer (NLB) endpoints with TLS listeners. You can terminate TLS at your NLB and still see the original client IP address in your application. This means you can apply security groups, geo-blocking, rate limiting, fraud detection, audit logging, allowlists, and compliance controls based on the real client IP.

Previously, you couldn't add an NLB with a TLS listener to an accelerator that had client IP address preservation enabled. You had to choose between terminating TLS at the NLB and seeing the real client IP address. With this launch, you get both. This helps with workloads that need TLS termination at Layer 4, such as non-HTTP TCP protocols, applications that require static or Elastic IP addresses, and high-throughput traffic where a Layer 7 load balancer isn't a fit.

Recent findings suggest that to enable this feature, add an NLB with a TLS listener as an endpoint to an accelerator with client IP address preservation setting turned on, the same way you add any NLB. No additional configuration is required! Client IP address preservation for NLBs with TLS listeners is available at no additional charge in all AWS commercial Regions, excluding the AWS GovCloud (US) and China Regions. Standard Global Accelerator pricing applies.

To learn more, see Client IP address preservation in the AWS Global Accelerator Developer Guide and Create a listener for your Network Load Balancer in the User Guide for Network Load Balancers.
