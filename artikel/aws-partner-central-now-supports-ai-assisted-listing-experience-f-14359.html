AWS Partner Central now supports AI-assisted listing experience for product, services, and solutions

🌐 Source: Amazon • 📅 19 Nov 2026 • ⏱️ 1 min read (277 words, 📖 Standard)
💡 Key Takeaways
  • Industry observers note that AWS Marketplace search, Agent Mode, and AWS sales teams use listings to recommend partner offerings to AWS customers.
  • Partners can position products and professional services as distinct solutions for different industries, use cases, or outcomes.
  • In a recent development, these capabilities are available now to AWS Marketplace partners in all AWS Regions, except the AWS GovCloud (US) Regions and the China Regions.

Industry observers note that AWS Marketplace search, Agent Mode, and AWS sales teams use listings to recommend partner offerings to AWS customers. Partners who sell software and services can now create and improve their listings in AWS Partner Central with the latest AI-assisted listing experience. It drafts content from a partner's website and other materials, then highlights which sections need clearer details, use cases, or evidence of customer outcomes. For single-AMI products, it also drafts the usage instructions buyers see after subscribing. Partners see, for each section, whether it meets what buyers look for, and choose which suggestions to use and review all content before publishing.

Partners can position products and professional services as distinct solutions for different industries, use cases, or outcomes. Each solution gets its own AWS Marketplace page, bringing its case studies and AWS Specializations together with the listing's pricing, reviews, and trust information, so buyers can evaluate and buy from the same page. Buyers can filter search results by Specialization. Partners not ready to share public pricing can publish without it using leads-only listings, through which interested customers request a private offer that reaches the partner as a lead in AWS Partner Central. Partners can test metering and billing setup before publishing, and ask the assistant metering questions while integrating.

In a recent development, these capabilities are available now to AWS Marketplace partners in all AWS Regions, except the AWS GovCloud (US) Regions and the China Regions. To get started, open AWS Partner Central and choose "Products and services" or "Solutions". To learn more, see AI-assisted listing experience and Deciding what to list in the AWS Marketplace Seller Guide.
