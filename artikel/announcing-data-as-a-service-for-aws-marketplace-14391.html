According to recent reports, customers purchase Data as a Service products through public or private offers, and charges appear on their existing AWS invoice. For example, an investment team evaluating private companies can connect its AI agents to private-market data through an API and to credit analysis through a Model Context Protocol (MCP) server.

It has been revealed that sellers set their own prices and license terms, using a contract, pay-as-you-go, or contract with consumption pricing model for each product. They can add a free trial to any of these models, or offer a product for free. They also define the onboarding and delivery experience, from setting up the customer's account to providing the data through an API, a web portal, a real-time feed, an Amazon Simple Storage Service (Amazon S3) bucket, or another approach.

To learn more, explore Data as a Service products on AWS Marketplace, the AWS Marketplace Buyer Guide, and the AWS Marketplace Seller Guide.
