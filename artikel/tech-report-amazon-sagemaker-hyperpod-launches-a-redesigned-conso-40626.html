Tech Report: Amazon SageMaker HyperPod launches a redesigned console experience for creating Amazon EKS-orchestrated clusters

🌐 Source: Amazon • 📅 23 Nov 2026 • ⏱️ 1 min read (152 words, 📖 Standard)
💡 Key Takeaways
  • It has been revealed that amazon SageMaker HyperPod now offers a redesigned AWS Management Console experience for creating clusters orchestrated by Amazon EKS.
  • Recent findings suggest that you can start with smart defaults or choose a workload profile that applies a coordinated set of settings based on how you plan to use the cluster.
  • In a recent development, the redesigned experience is available in all AWS Regions where Amazon SageMaker HyperPod is available.

It has been revealed that amazon SageMaker HyperPod now offers a redesigned AWS Management Console experience for creating clusters orchestrated by Amazon EKS. A guided workflow helps ML infrastructure administrators and platform teams set up networking, instance groups, storage, permissions, resiliency, observability, lifecycle scripts, and tags. Required settings are kept apart from optional ones. You enter only what is needed to create the cluster and add other capabilities later, when you need them.

Recent findings suggest that you can start with smart defaults or choose a workload profile that applies a coordinated set of settings based on how you plan to use the cluster. You can then adjust individual and advanced settings as needed, reducing repetitive setup while retaining control over the configuration.

In a recent development, the redesigned experience is available in all AWS Regions where Amazon SageMaker HyperPod is available. To learn more, check our documentation.
