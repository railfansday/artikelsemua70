AWS CloudFormation makes resource coverage comprehensive with 206 latest types

🌐 Source: Amazon • 📅 24 Nov 2026 • ⏱️ 1 min read (145 words, ⚡ Quick Read)
💡 Key Takeaways
  • AWS CloudFormation now supports 206 additional resource types across 88 services, including Amazon SageMaker Hub, Amazon Bedrock AgentCore PolicyEngine, and Amazon EC2 Snapshot.
  • CloudFormation resource coverage is available across all AWS Regions where the underlying service is available.
  • To learn more, visit the AWS resource and property types reference, the Cloud Control API resource list, and the AWS CloudFormation User Guide.

AWS CloudFormation now supports 206 additional resource types across 88 services, including Amazon SageMaker Hub, Amazon Bedrock AgentCore PolicyEngine, and Amazon EC2 Snapshot. This closes key gaps in CloudFormation coverage and helps customers to standardize on safe and scalable infrastructure management workflows. The launch utilized a newly introduced AI-driven internal framework to collapse the costs of onboarding resource types to CloudFormation, setting up CloudFormation for continued coverage expansion. AWS Cloud Control API supports all new resource types that CloudFormation supports. Additionally, Cloud Control API now supports 224 read-only resource types across 99 services, making it easier to find and inspect existing AWS resources.

CloudFormation resource coverage is available across all AWS Regions where the underlying service is available.

To learn more, visit the AWS resource and property types reference, the Cloud Control API resource list, and the AWS CloudFormation User Guide.
