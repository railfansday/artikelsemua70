Across Europe, organizations handling sensitive workloads in regulated sectors — such as financial services, healthcare, critical infrastructure, and the public sector — are trying to modernize their infrastructure while adhering to strict local data governance standards, including SecNumCloud in France and BSI C3A in Germany.

In a recent development, to help organizations accomplish this, Google Cloud Dedicated provides the architectural, security, and API consistency of Google Cloud in locally governed environments managed by independent domestic operators. But infrastructure is only the starting point. Organizations also need to transform the software ecosystem they rely on every day.

To meet regional sovereignty requirements, organizations acquire and run these software solutions through trusted local entities — such as S3NS in France (a joint venture majority-owned and managed by Thales) and a newly formed German entity that will also be owned and managed by Thales, currently in preview. These local entities operate dedicated infrastructure stacks, help maintain operational custody, and handle customer data within independent jurisdictional boundaries.

Today, we are highlighting the expanding independent software vendor (ISV) ecosystem validated on Google Cloud Dedicated, enabling French and German organizations to run their critical enterprise software in environments designed to support their sovereign and regulatory needs.

Deploying in a sovereign boundary should not require an organization to sacrifice software choice or rewrite its enterprise applications.Because Google Cloud Dedicated provides architectural and API consistency with Google Cloud, validated enterprise software runs directly inside these partner-operated environments without custom re-platforming.

This model provides European enterprises with three concrete advantages:.

Localized operational custody: Infrastructure operations, software quarantine procedures, and day-to-day administrative access are under the direct management of local European partners operating with specialized remote technical escalations governed by strict, partner-supervised escorted access controls.

Broad software choice: Regulated institutions can deploy industry-standard tools for identity governance, cyber resilience, simulation, and data streaming natively in their sovereign perimeter.

Streamlined compliance: Organizations fulfill national frameworks like SecNumCloud and BSI guidelines while preserving familiar CI/CD pipelines, APIs, and developer workflows.

When highly regulated European institutions consider moving to a sovereign cloud, the infrastructure itself is rarely the primary roadblock. The real bottleneck is software.Historically, pursuing strict sovereignty meant accepting compromises:.

Rewriting applications from scratch or maintaining custom, brittle tooling because mainstream enterprise platforms were unavailable.

Forcing security, engineering, and data teams to abandon the industry-standard tools they use daily in favor of untested niche alternatives.

Sidelining high-impact initiatives like real-time fraud scoring, automated DevSecOps, and modern identity governance simply because the required ISVs could not legally or technically operate in the environment.

Because Google Cloud Dedicated maintains architectural and API consistency with Google Cloud, leading global and European software providers can deploy their proven platforms directly inside national, domestic operator-managed boundaries. Regulated organizations retain the software, automated pipelines, and operational standards they rely on — without sacrificing compliance or operational custody.

Deploying enterprise software on Google Cloud Dedicated and S3NS isn't just about hosting an application locally; it’s about pairing proven software engines with sovereign operations. Here is how these joint architectures unlock strategic value for European enterprises:.

Cohesity on Google Cloud Dedicated (Sovereign cyber resilience): Cohesity has many options to meet organizational data sovereignty objectives, whether on-premises or in the cloud with Google Cloud Dedicated. This is done through a unified, cyber resilient, AI-powered data platform — Cohesity Data Cloud — that is sovereign-by-design, making it easier to protect, manage, recover, and have visibility into data, while supporting compliance with data sovereignty requirements. For example, running Cohesity directly in the S3NS perimeter combines Cohesity’s Zero Trust cyber resilience architecture designed for immutability with local operational custody. Customers gain advanced threat hunting, cyber vaulting, and recovery orchestration that powers quick, clean, and trusted cyber-recovery from ransomware threats without allowing diagnostic telemetry, secondary backup copies, or operational keys to traverse external networks.

Proprietary source code, vulnerability scans, and CI/CD artifact registries stay contained behind the partner-operated boundary, significantly reducing audit friction of using public SaaS code repositories.
