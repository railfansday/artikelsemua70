Amazon Route 53 now offers Advanced Hosted Zones

In a recent development, amazon Route 53 now offers Advanced Hosted Zones, a new hosted zone tier with additional guardrails, visibility, and resilience features. Advanced Hosted Zones include Change Guardrails that prevent accidental record deletions, record-level Change History, and public DNS fallback in private hosted zones.

It has been revealed that A single mistaken DNS change can take part of your domain offline, such as deleting a record that is still serving traffic or removing a delegation that resolvers are still using. To protect against this, customers build their own validation pipelines, review processes, and audit tooling. With Change Guardrails turned on, Route 53 checks each change before applying it. It blocks deleting a record that is still receiving DNS queries, a record that an alias record in the same hosted zone points to, or a delegation that is still in use. When a guardrail blocks a change, Route 53 rejects the whole request with an error that explains why, and no records change. Guardrails apply to every change, including changes from infrastructure as code tools. Change History gives you a record-level history of changes to your hosted zone, retained for 365 days, so you can see what changed and when.

To get started, create a upcoming Advanced Hosted Zone or upgrade an existing hosted zone, then turn on the guardrails you want. You can use the Route 53 console, API, AWS CLI, AWS SDKs, or AWS CloudFormation. Advanced Hosted Zones are priced separately from Standard Hosted Zones. For rates, see the Route 53 pricing page.

Industry observers note that advanced Hosted Zones are available in all AWS commercial Regions where Route 53 public and private hosted zones are available. To learn more, see Advanced Hosted Zones in the Route 53 Developer Guide.
