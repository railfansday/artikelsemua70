Breaking: AWS Security Hub now detects when vulnerable software is running on Amazon EC2 instances

🌐 Source: Amazon • 📅 16 Nov 2026 • ⏱️ 1 min read (234 words, 📖 Standard)
💡 Key Takeaways
  • It has been revealed that AWS Security Hub now detects when software with a known vulnerability is actively running on your Amazon EC2 instances.
  • Recent findings suggest that security teams managing thousands of instances can now prioritize patching based on actual runtime risk.
  • In a recent development, this capability is available at no additional cost with the AWS Security Hub Essentials proposal in all AWS Regions where Security Hub is available .

It has been revealed that AWS Security Hub now detects when software with a known vulnerability is actively running on your Amazon EC2 instances. Exposure findings now include a new trait, *The EC2 instance is running software with a known vulnerability*. These findings get a higher severity rating than findings for the same vulnerability where the software isn't running. This helps your security team focus on the vulnerabilities that pose the greatest risk, without investing time and resources to investigate if the software is actually in use.

Recent findings suggest that security teams managing thousands of instances can now prioritize patching based on actual runtime risk. Security Hub correlates data from Amazon GuardDuty Runtime Monitoring and Amazon Inspector VM Scanner to detect running vulnerable software. It then combines this with other signals to generate exposure findings for EC2 resources that may be at risk, so you can prioritize response and remediation.

In a recent development, this capability is available at no additional cost with the AWS Security Hub Essentials proposal in all AWS Regions where Security Hub is available . To learn more, see the AWS Security Hub User Guide, the exposure definition in Remediating exposures for EC2, the AWS Security Hub product page, the GuardDuty Runtime Monitoring User Guide, and the Amazon Inspector VM Scanner User Guide. For the full list of Regions, see the AWS Regional Services List.
