Latest Update: AWS Glue adds 100 new native connectors for popular SaaS applications

🌐 Source: Amazon • 📅 09 Nov 2026 • ⏱️ 1 min read (247 words, 📖 Standard)
💡 Key Takeaways
  • In a recent development, AWS Glue now supports 100 upcoming native connectors that simplify access to data in popular SaaS and REST API-based applications.
  • According to recent reports, the new connectors span generative AI, finance, payments, marketing, product analytics, human resources, engineering, IT operations, and collaboration tools.
  • The 100 fresh AWS Glue connectors are available in all AWS Commercial Regions on Glue versions 5.0 and above.

In a recent development, AWS Glue now supports 100 upcoming native connectors that simplify access to data in popular SaaS and REST API-based applications. Previously, bringing data from SaaS applications into AWS required writing custom code. Now, teams can create a connection once in the AWS Glue Data Catalog and reuse it across ETL jobs with the same permissions model they already use for AWS Glue.

According to recent reports, the new connectors span generative AI, finance, payments, marketing, product analytics, human resources, engineering, IT operations, and collaboration tools. AI teams can bring usage and cost data from model providers such as Anthropic to track generative AI adoption and spend. Finance teams can consolidate transactions from applications such as Adyen, Square, and Xero for faster reporting. Product and marketing teams can combine billing, usage, and campaign data from tools such as Chargebee, Amplitude, and Klaviyo to understand customer lifetime value. HR teams can unify workforce data from systems such as BambooHR and Gusto for headcount planning. Engineering teams can join incident and deployment data from tools such as PagerDuty, Sentry, Jenkins, and Vercel to track reliability. You can load the integrated data into Amazon S3 or Amazon Redshift for analytics and reporting.

The 100 fresh AWS Glue connectors are available in all AWS Commercial Regions on Glue versions 5.0 and above.

To learn more, see the complete list of available connectors and learn about connecting to individual connectors in the AWS Glue documentation.
