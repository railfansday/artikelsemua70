Amazon MSK Standard Brokers now support Graviton4-based M8g instances

🌐 Source: Amazon • 📅 17 Nov 2026 • ⏱️ 1 min read (122 words, ⚡ Quick Read)
💡 Key Takeaways
  • AWS Graviton4-based M8g instances are now generally available for Standard Brokers in Amazon Managed Streaming for Apache Kafka (Amazon MSK).
  • Standard Brokers on M8g are available today across all AWS regions where MSK Standard Brokers and M8g instances are available.

AWS Graviton4-based M8g instances are now generally available for Standard Brokers in Amazon Managed Streaming for Apache Kafka (Amazon MSK). Compared to Standard Brokers on M7g, M8g delivers up to 35% lower P99 produce latency and 30% faster catch-up for consumers that fall behind.

Standard Brokers on M8g are available today across all AWS regions where MSK Standard Brokers and M8g instances are available. For pricing, refer to the Amazon MSK pricing page. To get started, use the AWS Management Console or API to create a upcoming cluster with Standard Brokers on M8g or start an in-place migration of an existing cluster from Standard Brokers on M7g to M8g. To learn more, see the Amazon MSK Developer Guide.
