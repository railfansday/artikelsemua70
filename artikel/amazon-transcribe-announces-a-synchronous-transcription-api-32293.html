📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Amazon Transcribe now offers a synchronous transcription API, TranscribeAudio. Send a complete audio file in a single request and get the full transcript back in the same response. There is no job to start, no status to poll, no connection to manage. The transcripts are as accurate as Amazon Transcribe batch transcription, so you can add fast, accurate speech-to-text to interactive applications such as voice assistants, agent-assist tools and on-demand "transcribe this clip" features.

The synchronous API supports the Amazon Transcribe features you already use, including:.

Send audio inline (up to 25 MB) or from Amazon S3 (up to 500 MB), 0.5 seconds to 1 hour long, in WAV, MP3, FLAC, M4A, MP4, Ogg, WebM or AMR format. The transcript comes back in the response, or Transcribe can write it to an S3 location you choose. Pricing is $0.0070 per minute of audio, billed per second, with speaker diarization, language identification, custom vocabulary and channel identification included. Two-channel audio is billed once on file duration. PII redaction is available as an add-on.

Industry observers note that supports English, Spanish, French, Italian, German, Japanese, Portuguese, Korean and Chinese (Simplified, Traditional and Hong Kong). Available in US East (N. Virginia, Ohio), US West (Oregon), Canada (Central), Europe (Ireland, London, Frankfurt), Asia Pacific (Mumbai, Singapore, Sydney, Tokyo, Seoul) and South America (São Paulo), with PII redaction available in all stated Regions except South America (São Paulo).

To get started, see Amazon Transcribe API Reference and the Amazon Transcribe pricing page.
