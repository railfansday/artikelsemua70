Latest Update: AWS Agent Registry now supports WebBotAuth bot registration

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (170 words, 📖 Standard)
💡 Key Takeaways
  • According to recent reports, AWS Agent Registry now supports registering WebBotAuth (WBA) bots as a latest record type, making it easier to verify legitimate bot traffic through a standardized protocol.
  • In a recent development, this upcoming capability gives content providers and application developers fine-grained control over which bots can access your resources.
  • This feature is available in all AWS Regions where AWS Agent Registry is available.

According to recent reports, AWS Agent Registry now supports registering WebBotAuth (WBA) bots as a latest record type, making it easier to verify legitimate bot traffic through a standardized protocol. Previously, organizations lacked a standardized way to distinguish verified bots from malicious traffic. Now, bots can prove domain ownership through WebBotAuth, and you can integrate this verification with AWS WAF Bot Control to write rules that combine verification status and bot identity.

In a recent development, this upcoming capability gives content providers and application developers fine-grained control over which bots can access your resources. You can enhance security and improve traffic management by distinguishing legitimate bots from malicious actors. For example, you can allow WBA verified search engine crawlers while blocking unverified traffic or create custom access policies based on both bot identity and verification status.

This feature is available in all AWS Regions where AWS Agent Registry is available. To learn more, visit the AWS Agent Registry documentation and the AWS WAF Bot Control documentation.
