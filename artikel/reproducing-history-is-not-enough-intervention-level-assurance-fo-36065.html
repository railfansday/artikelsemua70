Reproducing History Is Not Enough: Intervention-Level Assurance for LLM-Generated Simulators

🌐 Source: Arxiv • 📅 26 Nov 2026 • ⏱️ 2 min read (300 words, 📖 Standard)

In a recent development, arXiv:2611.31736v1 Announce Type: new Abstract: Large language models can now write simulation programs of operational processes and workflows. These programs can be reused to answer what-if questions on new records and policies. However, a program that reproduces recorded history can still give wrong answers to what-if questions; requested changes may be applied wrongly, or they may be applied to records other than the ones the question is about, or the program may stop being valid once its policy is revised. Current checks return a pass-or-fail verdict for the whole program, which indicates little about whether any single answer can be trusted. We propose Vouch, a library that judges whether an answer from a generated simulator can be trusted for the change being asked about. Each what-if question is turned into a structured change, which is checked against the program and the current records. The library also keeps a record of the kinds of change each program has passed or failed, and repeats the relevant tests whenever the program is reused. We apply it to three program-generation platforms, with programs built by five language models, across four domains: manufacturing, IT operations, and pharmacy and loan-application workflows, using independently checked reference answers. Our baselines are the platforms' own checks where such checks exist, an LLM-as-a-judge, and a ReAct agent that can run the program. We measure how many correct answers are trusted, how many are wrongly rejected, how many wrong answers are accepted, and what the checking costs. On programs written by Haiku and Sonnet in one platform, Vouch removes 97.6% of the wrong answers, while still trusting 80.1% of all answers. At equal coverage, it accepts fewer wrong answers than LLM judges built on Claude Haiku. We disclose code and results for reproducibility.
