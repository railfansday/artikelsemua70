Industry observers note that we’re introducing the Admin plugin for ChatGPT Work⁠(opens in a new window) and Codex⁠(opens in a new window)—a faster, easier way to analyze workspace information, update settings, and act on requests. In one conversation, admins can ask a question, explore the details, make an authorized change, and confirm the result—without writing complex prompts or switching between tools.

In a recent development, managing a growing workspace often means moving between analytics, settings, and reports to understand complications and take action. This makes routine admin work slower and harder to complete consistently. By bringing admin analytics and supported actions together, the Admin plugin helps teams keep growing workspaces secure, productive, and within budget.

With the Admin plugin, admins can complete their day-to-day tasks directly from ChatGPT Work and Codex, including but not limited to:.

Recent findings suggest that understand adoption and usage. Review activity and credit usage across ChatGPT Work and Codex, identify where additional enablement may help and when members or groups are approaching credit limits.

Manage members and groups. Add or remove members, revision groups, and complete routine onboarding, offboarding, and team changes.

Recent findings suggest that manage access and permissions. Review effective permissions, diagnose access issues, and control feature or model access by role or group.

Manage usage limits and spending requests. Adjust limits for members groups, and workspaces, review requests against current usage, and approve or deny them with context.

Industry observers note that admins can also use the Admin plugin to automate recurring checks and high-volume requests—without custom engineering. These automations reduce manual monitoring, apply policies more consistently, and let admins focus on decisions that require their judgment.

Industry observers note that for example, the plugin can route pending usage requests to Slack or Microsoft Teams, where authorized reviewers can approve or deny them within the tools they already use. It can also monitor feature-access requests and automatically grant access when they meet predefined criteria, while routing exceptions for review. Admins remain in control throughout, and each workflow confirms when requested changes have been applied.

Sources indicate that the Admin plugin works within each user’s existing role and permissions; it does not grant broader access. Behind each request, the plugin maps the admin’s instructions to the appropriate supported read or write action and returns a structured result. It makes Admin Console capabilities available to ChatGPT Work and Codex as permission-aware tools, while honoring workspace policies and approval requirements.

It has been revealed that for each change, admins can see what they requested, whether the action completed, and what changed. They can review actions with broader impact before those actions are applied.

Sources indicate that at OpenAI, the Admin plugin changes the first step of workspace administration for the IT team. With the plugin, the team can simply ask questions to drill into the data, and generate reports and insights.

According to recent reports, the Admin plugin is one example of a broader shift in how OpenAI’s IT team uses ChatGPT Work and Codex. OpenAI’s IT team uses these tools to bring the relevant context and workflows into one place.

Sources indicate that in Slack, a ChatGPT Work agent handles employee IT requests, triages and actions support tickets, retrieves context, checks approved policies, completes supported tasks, and escalates exceptions. At the time of reporting, deployed workflows resolved about ~45% of ticket volume.

According to recent reports, chatGPT Work made it possible to turn support ticket data and history into operational health dashboards, giving IT continuous visibility into service performance. That visibility helped eliminate the backlog and changed how the team operates. Instead of reacting to service issues, the team now uses live data to set priorities and blueprint for demand, even as support volume roughly doubled.

According to recent reports, getting started with the plugin in a few simple steps. First, enable the plugin in ChatGPT workspace settings, then install it from the Plugins directory in ChatGPT Work on the web or desktop app. Once installed, admins can manage day-to-day workspace tasks faster and more consistently.
