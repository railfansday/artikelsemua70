Amazon Aurora and RDS now support Graviton5-based R9g database instances

🌐 Source: Amazon • 📅 12 Nov 2026 • ⏱️ 1 min read (188 words, 📖 Standard)
💡 Key Takeaways
  • AWS Graviton5-based R9g database instances are now generally available for Amazon Aurora with PostgreSQL compatibility and MySQL compatibility, and for Amazon RDS for PostgreSQL, MySQL, and MariaDB.
  • Sources indicate that you can get started using the R9g database instances through the Amazon RDS Management Console or by using the AWS Command Line Interface (CLI).

AWS Graviton5-based R9g database instances are now generally available for Amazon Aurora with PostgreSQL compatibility and MySQL compatibility, and for Amazon RDS for PostgreSQL, MySQL, and MariaDB. Graviton5-based R9g instances provide up to a 30% performance improvement and up to a 22% price-performance improvement for on-demand pricing over Graviton4-based instances of equivalent sizes on Amazon Aurora, depending on database engine, version, and workload. Built on the AWS Nitro System, R9g instances are available in nine sizes, from large to 48xlarge. They deliver up to 192 vCPUs, an 8:1 ratio of memory to vCPU, up to 100 Gbps of networking bandwidth, and up to 72 Gbps of bandwidth to Amazon Elastic Block Store (Amazon EBS).

Sources indicate that you can get started using the R9g database instances through the Amazon RDS Management Console or by using the AWS Command Line Interface (CLI). The instances are available in US East (N. Virginia, Ohio), US West (Oregon), and Europe (Frankfurt) regions. For the specific engine versions that support these instance classes, see the Aurora and RDS documentation. For pricing, see Amazon Aurora pricing and Amazon RDS pricing.
