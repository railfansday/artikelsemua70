AWS Lambda durable functions now supports OpenTelemetry tracing

🌐 Source: Amazon • 📅 19 Nov 2026 • ⏱️ 1 min read (223 words, 📖 Standard)

Recent findings suggest that AWS Lambda unveils OpenTelemetry (OTel) support for Lambda durable functions. You can now trace your durable executions and emit traces to Amazon CloudWatch and other industry-standard observability tools. This helps you find bottlenecks in your system, root cause failures faster, and understand how your workflows behave in production.

In a recent development, with Lambda durable functions, you can build resilient, multi-step applications and AI workflows that run for up to one year, with built-in checkpointing and automatic retries. Durable functions can run for hours, or days, suspending and resuming across many Lambda invocations. The fresh OpenTelemetry plugin emits a unified trace that spans a full durable execution, including steps, waits, callbacks, and chained function invocations. You can use the trace to gain operational insights across your executions including step durations, retries, and failures across executions.

The OpenTelemetry plugin is available for the TypeScript, Python, and Java SDKs. You can enable OpenTelemetry support by adding the OpenTelemetry plugin package alongside the Durable Execution SDK and register it on your durable handler or using an environment variable. OpenTelemetry support for Lambda durable functions is available in all AWS Regions that support Lambda durable functions.

To get started, see the  OpenTelemetry plugin documentation, the plugin interface documentation, and the sample application. To learn more, read the blog post.
