AWS Secrets Manager adds managed external secrets support for Auth0, Okta, and Palo Alto Networks

🌐 Source: Amazon • 📅 16 Nov 2026 • ⏱️ 1 min read (242 words, 📖 Standard)
💡 Key Takeaways
  • AWS Secrets Manager now supports managed external secrets for Auth0, Okta, and Palo Alto Networks.
  • Industry observers note that secrets Manager offers self-rotation and administrator-assisted rotation for Auth0 credentials.
  • Applications that already retrieve credentials from Secrets Manager receive the rotated value without a code change or deployment.
📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

AWS Secrets Manager now supports managed external secrets for Auth0, Okta, and Palo Alto Networks. Long-lived credentials that are not rotated increase the risk of unauthorized access if exposed. Rotating a third-party credential requires coordinated updates to the external service and every application that uses it. You set a rotation schedule from the AWS Management Console or API. Secrets Manager rotates the credential and stores the current value without a custom rotation Lambda function.

Industry observers note that secrets Manager offers self-rotation and administrator-assisted rotation for Auth0 credentials. With self-rotation, the target application replaces its own secret. With administrator-assisted rotation, a separate Auth0 application with Management API permissions replaces the target application's secret. For Okta, Secrets Manager offers administrator-assisted rotation with a separate administrator JSON Web Token (JWT) key and validates the replacement before deactivating the old secret. For Palo Alto Networks, Secrets Manager offers self-rotation, in which the current API key authorizes its replacement.

Applications that already retrieve credentials from Secrets Manager receive the rotated value without a code change or deployment.

These integrations join existing managed external secrets support for BigID, Cisco Security Platform, Confluent Cloud, Databricks, Datadog, GitLab, Jenkins, MongoDB Atlas, Netskope, Paddle, Salesforce, Snowflake, SonarQube, and Twilio.

Auth0, Okta, and Palo Alto Networks managed external secrets are available in all AWS Regions where AWS Secrets Manager managed external secrets is supported. To learn more, visit the  AWS Secrets Manager managed external secrets documentation .
