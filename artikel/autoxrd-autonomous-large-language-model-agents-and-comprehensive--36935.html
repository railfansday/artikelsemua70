AutoXRD: Autonomous Large Language Model Agents and Comprehensive Evaluation for Powder X-Ray Diffraction Analysis

🌐 Source: Arxiv • 📅 26 Nov 2026 • ⏱️ 1 min read (244 words, 📖 Standard)

arXiv:2609.00070v2 Announce Type: replace-cross Abstract: Powder X-ray diffraction (XRD) is a foundational technique for structural and phase characterization in materials science, yet automating its analysis and evaluating it end-to-end remains challenging. Doing so requires an agent to interpret diffraction patterns, run refinement software, manage strongly coupled parameters in a physically meaningful order, and assess both numerical fit quality and physical validity. We propose AutoXRD, an LLM agent framework that organizes powder XRD analysis into refinement stages, uses diffraction diagnostics to select actions, and checks the resulting fits against crystallographic and physical criteria. We further introduce XRDBench with two complementary tracks. XRDBench-QA contains 100 tasks assessing scientific reasoning and decision-making, whereas XRDBench-E2E contains 34 end-to-end workflows requiring data interpretation, crystallographic software execution, iterative refinement, evidence preservation, and reporting. Across 1,340 runs of ten recent LLMs, models average only 57.8 out of 100, falling from 61.9 on XRDBench-QA to 53.7 on XRDBench-E2E. At the task level, they perform best on refinement-history assessment and result acceptance, but remain substantially weaker on refinement-action selection, phase quantification, indexing, and Rietveld refinement. Among individual models, GPT-5.6 Sol achieves the highest overall score of 81.1, GPT-5.6 Terra scores highest on XRDBench-E2E (81.0), and GPT-5.6 Luna provides the best score-cost trade-off. Moreover, ablations confirm that all six AutoXRD components consistently improve performance. Finally, execution-trace analysis reveals recurring failures in coupled-parameter control, quantitative reasoning, evidence preservation, and workflow termination, motivating stronger scientific constraints, uncertainty quantification, and more efficient planning.
