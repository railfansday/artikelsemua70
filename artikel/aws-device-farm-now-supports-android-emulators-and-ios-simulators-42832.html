AWS Device Farm now supports Android emulators and iOS simulators

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

In a recent development, AWS Device Farm, a service for testing mobile and web apps, now supports Android emulators and iOS simulators alongside real devices for automated and manual testing, enabling faster testing at scale early in your development pipeline. With virtual devices, you can shift testing left to stages that need high speed and volume, such as pull requests, code merges, and smoke tests, and keep real devices for later stages that need high fidelity, such as regression and release testing. Virtual devices running the latest device and OS typically start in seconds, and others start in around a minute.

Industry observers note that previously, you could build and maintain your own Android emulator and iOS simulator infrastructure, which requires separate tooling and compute such as Mac hosts for iOS, or run every stage on real devices, which is slower, limited by device availability, and costs more than early-stage testing needs. Now you can use the same fully managed Device Farm APIs, test environment, private endpoint access, and test frameworks for both virtual and real devices. To switch, you change only the device type, so your pipeline and tests stay the same and you avoid maintaining two separate orchestration layers.

Virtual devices use the existing metered pricing. For Android, your existing unmetered slots now go further and run either a real or a virtual device at no additional charge.

Android emulators and iOS simulators are available in all AWS Regions where AWS Device Farm is offered.

To get started, see the AWS Device Farm Developer Guide.
