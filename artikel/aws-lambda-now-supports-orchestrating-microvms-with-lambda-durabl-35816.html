AWS Lambda now supports orchestrating MicroVMs with Lambda durable functions

🌐 Source: Amazon • 📅 25 Nov 2026 • ⏱️ 2 min read (319 words, 📖 Standard)

  • It has been revealed that with Lambda durable functions, you can build resilient, multi-step applications and AI workflows that run for up to one year, with built-in checkpointing and automatic retries.
  • According to recent reports, the MicroVM extension is available as a developer preview for the AWS Durable Execution SDK for TypeScript and Python.

Today, AWS reveals a developer preview of a new extension for orchestrating Lambda MicroVMs with Lambda durable functions. The extension adds durable operations for running work on MicroVMs and managing their lifecycle. You can use the new operations to build software factories, security scanners, or orchestrate CI/CD jobs that run untrusted or agent-generated code in isolated sandboxes.

It has been revealed that with Lambda durable functions, you can build resilient, multi-step applications and AI workflows that run for up to one year, with built-in checkpointing and automatic retries. Lambda MicroVMs are a serverless compute primitive that provides VM-level isolation, near-instant launch and resume, and state preservation for running user-generated or AI-generated code. With this launch, you can run individual tasks in a MicroVM or launch a MicroVM session, where tasks share the same files and memory. The durable function manages the MicroVM lifecycle and runs each task as a durable operation. It checkpoints progress, retries failed tasks, and refreshes MicroVM tokens as needed. A single durable function can orchestrate multiple MicroVMs in parallel, and you can trigger it from event sources such as Amazon SQS or Amazon EventBridge. An optional worker library runs inside your MicroVM image to receive tasks, send heartbeats, and report results.

According to recent reports, the MicroVM extension is available as a developer preview for the AWS Durable Execution SDK for TypeScript and Python. To get started, add the extensions package to your function alongside the Durable Execution SDK (JS/TS, Python) and add the MicroVM worker library (JS/TS, Python) to your MicroVM image. Developer preview features may change, so do not use them for production workloads. The extension is available in all AWS Regions that support Lambda durable functions and Lambda MicroVMs.

To learn more, see the MicroVM orchestration documentation and the sample application. To share feedback, open an issue in the Durable Execution SDK GitHub repository in JavaScript or Python.
