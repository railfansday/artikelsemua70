📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

According to recent reports, AWS DevOps Agent now supports dedicated Slack code channels and two-way conversations in Microsoft Teams, so on-call engineers and DevOps teams can investigate and resolve incidents where they already work together. AWS DevOps Agent investigates incidents across AWS, multicloud, and on-premises environments.

Slack code channels give each investigation its own channel. Choose Open in code channel on an investigation card, and your team and the agent work on the investigation together in that channel. You can ask follow-up questions without @mentioning the agent. If you registered your Slack workspace before this launch, upgrade your Slack permissions to use code channels.

According to recent reports, for Microsoft Teams, before this launch, consumers received only one-way notifications from AWS DevOps Agent. Now you can mention AWS DevOps Agent in a connected private or shared channel to ask questions, explore your AWS resources, and steer investigations. The agent replies in a thread under your message. To get started, turn on Bidirectional mode when you associate the channel with your Agent Space. A channel member then authorizes the association before the agent posts.

These capabilities are available in all commercial AWS Regions where AWS DevOps Agent is currently supported.
