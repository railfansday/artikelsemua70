AWS WAF advanced rate-based rules are now available in AWS GovCloud (US), Thailand, and Mexico

🌐 Source: Amazon • 📅 16 Nov 2026 • ⏱️ 1 min read (139 words, ⚡ Quick Read)
💡 Key Takeaways
  • In a recent development, AWS WAF advanced rate-based rules are now available in the Asia Pacific (Thailand), Mexico (Central), AWS GovCloud (US-East), and AWS GovCloud (US-West) Regions.
  • You can configure these options in the AWS WAF console, the AWS CLI and SDKs, and AWS CloudFormation.

In a recent development, AWS WAF advanced rate-based rules are now available in the Asia Pacific (Thailand), Mexico (Central), AWS GovCloud (US-East), and AWS GovCloud (US-West) Regions. Customers in these Regions can now aggregate requests using custom keys and choose a 1 or 2 minute evaluation window in addition to the existing 5 and 10 minute options, the same capabilities already available in other AWS Regions.

You can configure these options in the AWS WAF console, the AWS CLI and SDKs, and AWS CloudFormation. There is no additional charge for these capabilities, and standard AWS WAF pricing applies. Advanced rate-based rules are now available in all commercial AWS Regions where AWS WAF is available and in the AWS GovCloud (US) Regions. To learn more, see Using rate-based rule statements in the AWS WAF Developer Guide.
