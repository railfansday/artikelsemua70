Tech Report: Announcing Test Insights for AWS Device Farm

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (183 words, 📖 Standard)
💡 Key Takeaways

  • With Test Insights, Device Farm's existing APIs now return enhanced test metadata, failure root cause with stack trace, a video for each test, start and stop times, median and average times spent on each device and test, and test counts by result.
  • Test Insights is included in all AWS Regions where Device Farm is available.

AWS Device Farm, a service for testing mobile and web apps, now provides Test Insights for Appium, Espresso, and XCUITest runs across multiple devices. Test Insights helps you and AI agents understand the health of your tests and resolve failures faster by providing a detailed breakdown of your test suite by device and by test.

With Test Insights, Device Farm's existing APIs now return enhanced test metadata, failure root cause with stack trace, a video for each test, start and stop times, median and average times spent on each device and test, and test counts by result. With this data in one place, your agents spend less time and fewer tokens looking for the root cause of test failures, and the AWS Device Farm troubleshooting skill uses it to help diagnose failed runs and suggest fixes. Test Insights is available alongside any default and custom test reports you generate, at no additional cost.

Test Insights is included in all AWS Regions where Device Farm is available.

To get started, see Test Insights in the AWS Device Farm Developer Guide.
