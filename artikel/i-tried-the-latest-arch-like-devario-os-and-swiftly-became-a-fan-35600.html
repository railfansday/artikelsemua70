Arch Linux isn’t the most user-friendly Linux distribution on the planet, and Hyprland isn’t ideal for those who want a simple desktop environment. Personally, I find Arch to be a great distribution, and Hyprland is one of the most efficient desktops I’ve ever come across. But for upcoming Linux users, that combination can be an absolute turnoff.

In a recent development, also: CachyOS vs. Arch Linux: There’s a reason one is DistroWatch’s top pick.

That’s why, when I came across Devario OS, something clicked: it is possible to have an Arch-like Linux distro with a Hyprland-like window compositor that’s more user-friendly. Yes, Devario OS is created in the mold of Arch Linux, but it opts for the Aqueous compositor, which is very similar to Hyprland — but better for upcoming Linux users.

Sources indicate that devario OS is an independent Linux distribution that maintains compatibility with the Arch Linux package ecosystem. What does that even mean?

The reason I bring up the above is that the ways Devario OS is similar to Arch and Hyprland make it familiar to those who have used either. At the same time, the way Devario OS does things differently makes it easier.

Let’s talk about package management. With Arch, you know you’re going to have to use the command line. Sure, you could install a GUI like Octopi, but that’s not nearly as user-friendly as you might hope. On top of that, the Octopi GUI (which is available to Arch) is installed via the Arch User Repository (AUR). If you’ve been paying close enough attention to Arch, then you know the problems the AUR has endured. If not, suffice it to say that a number of malicious apps have been uploaded to it that were then unknowingly installed by owners.

According to recent reports, with Devario OS, you get Shelly, which is one of the best Arch-like package manager GUIs on the market. Shelly is as easy to use as any package manager GUI around. It also integrates with Flatpak apps and AppImages, so I found tons of apps to install.

Another way Aqueous veers away from Hyprland is that it includes a handy dock. Out of the box, the dock doesn’t appear until you open an app; that’s because the dock has nothing pinned to it. Once you open an app, you can right-click (or two-finger tap) the icon in the dock and select “Pin to dock.” The dock has a handy feature that allows you to directly interact with apps, without having to first bring them back into focus. For example: if you have Shelly pinned to the dock, you can right-click (or two-finger tap) the icon and open the Flatpak Install section, open the Update section, or go to the Flatpak Remove section of the app.

In a recent development, with Firefox pinned to the dock, you can open the context menu and do things like open a new window, open a private window, open the profile manager, or go directly to a currently focused tab. It’s very handy.

According to recent reports, finally, although Devario OS/Aqueos calls itself a tiling window manager, it doesn’t really behave like one by default. Yes, you can snap windows, just like you can with most modern desktops, but when you open an app, it appears in the center of the screen. Open a second app, and it appears in the same spot, covering the original, where you can move it around at will. If this were a true tiling window manager, the first app would open full screen and the second app would then move the first to the left side of the display to take up the right side.

Pearl (the actual window manager) has a nice secret up its sleeve. If you open the Settings app and go to Layouts, you’ll find several options, one of which is Tiling. If you want Devario to use a tiling window manager, select Tiling and apply.

In a recent development, there’s also monocle, grid, rows, dwindle, reverse dwindle, scrolling, stacking, game-mode, and composable. I’d suggest testing each to see which one best suits you.

It has been revealed that what I really appreciate about Devario OS is that it takes the best of many worlds and blends them together into a Linux distribution that is sure to appeal to a wider cross-section of people than the technologies it is loosely based on. I quickly became a fan of Devario OS, even though it’s quite young in its development (the first stable iteration was released this month), and I strategy on revisiting it regularly to keep tabs on how it evolves.

Sources indicate that I would suggest you give Devario OS a try and see if you don’t fall for it immediately. You can download the ISO from the Seafoam-Labs site.
