Amazon EC2 Capacity Blocks for ML now supports search across multiple instance types and AWS Regions

🌐 Source: Amazon • 📅 23 Nov 2026 • ⏱️ 1 min read (202 words, 📖 Standard)
💡 Key Takeaways

  • Industry observers note that until now, customers looking to buy Capacity Blocks had to run a separate search for every instance type and Region combination.
  • It has been revealed that this feature is available for all Instance Capacity Blocks in AWS Regions where EC2 Capacity Blocks for ML are offered.

According to recent reports, amazon EC2 Capacity Blocks for ML now lets customers search across multiple instance types and AWS Regions in a single search, making it easier to find and reserve the capacity their ML workloads need. With Capacity Blocks for ML, customers can reserve accelerated compute instances such as Amazon EC2 P6-B300, P6-B200, and Trn2 instances, for a future start date and for up to 6 months.

Industry observers note that until now, customers looking to buy Capacity Blocks had to run a separate search for every instance type and Region combination. Starting today, customers can use a single search in the AWS Management Console to look for Capacity Blocks across multiple instance types and Regions, making it easier to secure capacity without repeated searches. Customers can also programmatically search for capacity across multiple instance types within a Region with a single API call using DescribeCapacityBlockOfferings.

It has been revealed that this feature is available for all Instance Capacity Blocks in AWS Regions where EC2 Capacity Blocks for ML are offered. For a complete list of supported regions, refer to Capacity Blocks documentation. To get started, visit the Capacity Blocks page in the Amazon EC2 console.
