📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Automated API discovery and protection are now generally available, enabling you to discover every API behind Amazon API Gateway, Application Load Balancers, and Amazon CloudFront across your AWS Organization and protect them using AWS WAF.

Discovery is available through the fresh API Gateway API Portal, which identifies the APIs automatically from traffic logs and service configuration records, with no agents to deploy or logs to forward. The API Portal classifies the APIs it finds, identifies zombie and shadow APIs, evaluates each API's security posture, and reports findings, including the ones that are missing WAF protections. For unprotected APIs, customers can enable protection using WAF.

Protection is available through the new AWS WAF API Security managed rule group, which protects your APIs against the most exploited API attack categories: Broken Object Level Authorization (BOLA), where the attackers change record IDs in requests to read other customers' data, Broken Authentication and Credential Stuffing, where the attackers forge tokens or try stolen passwords at scale, and API Reconnaissance and Enumeration, where the attackers map an API by guessing hidden routes and probing for exposed docs. The events detected by WAF are consolidated into the API Portal findings to provide a complete security picture of your APIs. You can use API Security alongside other AWS Managed Rules or your own custom rules to protect your applications.

Together, API Portal and API Security provide you a complete solution from discovery of all APIs in your AWS environment to protecting them, without having to write any custom rules.

According to recent reports, API Portal is available in 32 AWS Regions. See the Amazon API Gateway FAQ for the list. API Security is available in all AWS Regions where AWS WAF is available, except the AWS GovCloud (US) Regions, the China Regions, and the AWS European Sovereign Cloud.
