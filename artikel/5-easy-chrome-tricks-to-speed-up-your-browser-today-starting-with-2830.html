Chrome is the most widely used web browser on the planet, accounting for nearly 70% of the global web browser market share. But just because Chrome is the most popular browser doesn’t mean it’s always the fastest option. Fortunately, there are several simple ways to speed up Chrome without installing third-party software.

It has been revealed that there are also faster, more secure, and more feature-rich browsers available (my current favorite is Firefox). However, if you really do prefer Chrome, but still find it slow, here are a few things you can do to speed it up, including clearing your cache.

Also: I’ve used nearly every browser out there, and these are my top 4.

Note: I don’t recommend third-party software to speed up Chrome because it isn’t necessary, can cause problems, and may be malicious.

According to recent reports, chrome’s Memory Saver does one thing: frees up RAM from inactive tabs. This is important because without Memory Saver enabled, inactive tabs can continue to consume system resources. With Memory Saver enabled, that RAM is freed from those tabs, so it can be used by active tabs. What Memory Saver actually does is put inactive tabs to sleep. Sources indicate that with page preloading enabled, Chrome guesses which page or search result you are more likely to open next. Once it guesses, Chrome then preloads the page in the background, before you even click it. Chrome accomplishes this by inspecting the links on the page you’re at the moment viewing or the search results in your address bar and downloading the necessary resources for the pages it believes you’ll visit next. It doesn’t always guess right, but when it does, the increase in speed is noticeable.

Also: The most private and secure way to browse the web isn’t incognito mode.

Sources indicate that by default, standard preloading is enabled, which preloads a small set of likely pages. If you want to gain even more speed, you can enable “extended preloading,” which predicts and preloads pages across the web with the help of Google’s servers. Keep in mind, however, that extended preloading does send considerably more information to Google’s servers, so if privacy is key to you, you should consider either disabling preloading or sticking with the default.

According to recent reports, over the years that you’ve used Chrome, you might have installed various and sundry extensions, some of which you may no longer need. Even if you don’t use them, some of those extensions could be consuming system memory, thereby leaving fewer resources for Chrome.

You should regularly go back to the extensions feature and disable (or remove) any and all extensions you no longer use. To manage your Chrome extensions, open chrome://extensions and click “Remove” on any extension you no longer use. In some cases, you might be required to restart Chrome for the change to take effect.

I tend to keep a lot of tabs open, many of which I need at that moment or soon. Because of that, I will move the tabs I’m not right now using to Chrome’s reading list feature, so they are easily accessible. I do this because I no longer use the bookmarks feature. If you still use bookmarks, simply create bookmarks from those sites you know you’ll need and then close them.

According to recent reports, when Google updates Chrome, it sometimes adds features to speed up the browser. Even more importantly, it fixes vulnerabilities that could lead to security issues (or slowdowns). Whether Chrome is showing signs of slowing down or not, you should patch it regularly. To check for an update, go to the three-dot menu > Help > About Google Chrome. If there’s a pending update, it will be listed near the top, where you can click Relaunch to install it.
