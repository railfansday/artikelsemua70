Breaking: Amazon S3 Vectors raises the filterable metadata limit to 40 KB per vector

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (184 words, 📖 Standard)
💡 Key Takeaways
  • Amazon S3 Vectors now supports up to 40 KB of filterable metadata per vector, up from 2 KB.
  • S3 Vectors provides native support to store and query vectors in Amazon S3, delivering purpose-built, cost-optimized vector storage and query at billion-vector scale.
  • It has been revealed that the higher filterable metadata limit is available at no additional cost in all AWS Regions where Amazon S3 Vectors is available.

Amazon S3 Vectors now supports up to 40 KB of filterable metadata per vector, up from 2 KB. You can attach and filter on more attributes per vector, such as category, permissions, timestamps, and descriptive tags, so your retrieval-augmented generation (RAG), agentic, and semantic-search applications can narrow results by more of the fields that matter to them.

S3 Vectors provides native support to store and query vectors in Amazon S3, delivering purpose-built, cost-optimized vector storage and query at billion-vector scale. With this launch, indexes in new vector buckets support the higher limit by default, with no change to how you write vectors with PutVectors or run filtered queries with QueryVectors. To use the higher limit on an existing index, upgrade it in place to enhanced index mode with the UpdateIndexMode API.

It has been revealed that the higher filterable metadata limit is available at no additional cost in all AWS Regions where Amazon S3 Vectors is available. To get started, use the AWS CLI, AWS SDKs, or the Amazon S3 console. To learn more, visit the Amazon S3 Vectors documentation.
