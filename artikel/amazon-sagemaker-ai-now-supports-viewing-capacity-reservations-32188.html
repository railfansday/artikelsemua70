Amazon SageMaker AI now supports viewing capacity reservations

🌐 Source: Amazon • 📅 23 Nov 2026 • ⏱️ 1 min read (189 words, 📖 Standard)
💡 Key Takeaways
  • Industry observers note that amazon SageMaker AI now lets you view SageMaker Capacity Reservations in the SageMaker console, AWS CLI, and AWS SDKs.
  • Customers can view their SageMaker Capacity Reservations under Reserved Capacity section in SageMaker Console.
  • It has been revealed that this capability is available in all AWS Regions where Amazon SageMaker HyperPod is available.

Industry observers note that amazon SageMaker AI now lets you view SageMaker Capacity Reservations in the SageMaker console, AWS CLI, and AWS SDKs. Previously, customers had no self-service way to see their reserved capacity, including reservation timelines and instance availability, and had to rely on AWS Support to plan their own workloads. Starting today, administrators can review the capacity they hold without leaving SageMaker AI. Administrators can list reservations with their status, instance type, availability zone, instance count, start time, and end time.

Customers can view their SageMaker Capacity Reservations under Reserved Capacity section in SageMaker Console. They can open a reservation to see its details, including the ML reservation ARN to use in a SageMaker Inference Endpoint configuration. Additionally, the details page lists the SageMaker AI resources that can use the reservation, such as Amazon SageMaker HyperPod clusters and SageMaker Inference endpoints, and reveals the status of each association.

It has been revealed that this capability is available in all AWS Regions where Amazon SageMaker HyperPod is available. To learn more, see Amazon SageMaker HyperPod available regions and the Amazon SageMaker AI user guide.
