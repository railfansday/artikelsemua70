Amazon RDS for MySQL now supports MySQL major version 9.7

Starting today, Amazon RDS for MySQL supports MySQL major version 9.7, the latest Long-Term Support release from MySQL community. Amazon RDS for MySQL 9.7 launches with community MySQL 9.7.4. This launch introduces support for the Replication Applier Metrics component, JSON Duality Views, and Hypergraph Optimizer.

Industry observers note that the Replication Applier Metrics help you diagnose replication lag by adding two Performance Schema tables that report per-channel applier backlog, throughput, and wait statistics, along with each worker's progress on its current transaction. JSON Duality Views let applications read and write the same relational tables as JSON documents. The Hypergraph Optimizer is an opt-in query optimizer that can improve execution prepares for complex, multi-join queries. For more details, refer to the MySQL 9.7.4 release notes and the Amazon RDS for MySQL release notes.

Industry observers note that you can upgrade your database using Amazon RDS Blue/Green Deployments, in-place upgrade, or restore from a snapshot. Learn more about performing version upgrades in the Amazon RDS User Guide. This release is supported in all AWS Regions where Amazon RDS for MySQL is available. Learn more about pricing details at Amazon RDS for MySQL pricing.

Sources indicate that amazon RDS for MySQL makes it simple to set up, operate, and scale MySQL deployments in the cloud. Create or update a fully managed Amazon RDS database in the Amazon RDS Management Console or by using the AWS Command Line Interface (AWS CLI).
