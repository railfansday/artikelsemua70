Tech Report: AWS IoT Core now supports custom domain names for the AWS IoT credential provider

🌐 Source: Amazon • 📅 25 Nov 2026 • ⏱️ 2 min read (396 words, 📖 Standard)
💡 Key Takeaways
  • According to recent reports, AWS IoT Core now enables you to use configurable endpoints, including custom domain names, when your devices request temporary credentials from the AWS IoT credential provider to securely call other AWS services.

According to recent reports, AWS IoT Core now enables you to use configurable endpoints, including custom domain names, when your devices request temporary credentials from the AWS IoT credential provider to securely call other AWS services. Your devices can now use domains you own for both messaging and credentials, and hence AWS endpoint names need not be hard coded into device firmware. This makes it easier to manage, migrate, and scale your device fleet. The AWS IoT credential provider lets devices exchange their X.509 certificates for temporary credentials from AWS Security Token Service (AWS STS). Devices then use these credentials to call AWS services such as Amazon Kinesis Video Streams and Amazon Simple Storage Service. With the new launch, devices can use your own custom domain names to get credentials, the same way they already do for IoT messaging. This keeps your branding consistent and reduces the number of endpoints you configure on each device. Configurable endpoint support for AWS IoT credential provider endpoint is available in all AWS Regions where AWS IoT Core is available. AWS IoT credential provider endpoints are supported at no additional charge. For more information, refer to the AWS IoT Core developer guide.
