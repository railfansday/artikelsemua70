Recent findings suggest that today, we're announcing third-generation Amazon FSx for NetApp ONTAP file systems, which deliver up to 216 GB/s of throughput and 8.6 million SSD IOPS per file system, up to 3x more throughput and up to 3.6x more SSD IOPS than previous-generation file systems. Built on the latest AWS compute and storage technologies, third-generation file systems give you even more flexibility to scale performance as your workloads and usage patterns evolve.

FSx for ONTAP is the first and only storage service that allows you to launch and run fully managed, fully featured ONTAP file systems in the cloud. FSx for ONTAP file systems are powered by up to 12 highly available (HA) pairs of file servers to deliver storage and performance scalability. With previous-generation file systems, each HA pair delivers up to 6 GB/s of throughput and 200,000 SSD IOPS. With third-generation file systems, each HA pair delivers up to 18 GB/s of throughput and 720,000 SSD IOPS, giving you even more flexibility to scale your most demanding ONTAP workloads, such as chip design and verification, media rendering and video editing, and mission-critical databases.

FSx for ONTAP third-generation file systems are available today in the following AWS Regions: US East (N. Virginia, Ohio) and US West (Oregon). To learn more, visit the Amazon FSx for NetApp ONTAP product page and user guide.
