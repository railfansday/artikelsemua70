Amazon Cognito extends multi-Region replication to additional AWS Regions

It has been revealed that amazon Cognito multi-Region replication (MRR) now supports additional AWS Regions, extending the resilience benefits of MRR to more workloads. Amazon Cognito helps you implement secure sign-in and access control for people, AI agents, and microservices in minutes, and MRR lets you synchronize user and machine identity data, including credentials, user pool configurations, and federation setups, to a secondary user pool in a standby Region you designate in near real-time. With user data in the standby Region, you can redirect traffic and keep authentication available if there is a disruption in your primary Region.

Sources indicate that previously, MRR was available in 16 commercial Regions and the AWS GovCloud (US) Regions. You can now also use MRR to replicate your user data to Asia Pacific (Hyderabad, Hong Kong, Jakarta, Malaysia, Melbourne, New Zealand, Osaka, Taipei, Thailand), Canada West (Calgary), Europe (Milan, Spain, Zurich), Israel (Tel Aviv), Mexico (Central), Africa (Cape Town) Regions, helping you meet resilience, data residency, and compliance requirements in the Regions that best align with your needs.

In a recent development, MRR is available as an add-on for user pools on the Essentials or Plus feature looks, and requires a multi-Region AWS KMS customer managed key (CMK). For the full list of AWS Regions where Amazon Cognito is available, see AWS Capabilities by Region. To get started, visit the developer guide for instructions and the pricing page for pricing details.
