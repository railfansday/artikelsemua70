AWS debuts standardized cost and rate columns in CUR 2.0 and Cost Explorer

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (264 words, 📖 Standard)
💡 Key Takeaways
  • Sources indicate that AWS Data Exports for Cost and Usage Report (CUR) 2.0 now includes standardized cost and rate columns that represent cost consistently across AWS purchase options, including On Demand, Savings Aims, Reserved Instances, EC2 Spot, and EC2 Capacity Blocks for ML.
  • Previously, calculating savings required combining CUR with Savings Intends rates and public price lists, and amortized cost used different columns for each pricing model.
  • In a recent development, standardized cost and rate columns are available at no additional charge in all AWS Regions except the AWS GovCloud (US) Regions and the China Regions.

Sources indicate that AWS Data Exports for Cost and Usage Report (CUR) 2.0 now includes standardized cost and rate columns that represent cost consistently across AWS purchase options, including On Demand, Savings Aims, Reserved Instances, EC2 Spot, and EC2 Capacity Blocks for ML. These 14 columns are added when you enable Include Standardized cost and rate columns while setting up a latest CUR 2.0 export or editing an existing CUR 2.0 and these columns have the prefix cost_analytics_. With these new columns, you can quantify the savings you realize from commitments, discounts, and tiered pricing, and analyze amortized cost the same way for every pricing model with multiple payment options, directly in CUR 2.0.

Previously, calculating savings required combining CUR with Savings Intends rates and public price lists, and amortized cost used different columns for each pricing model. Now each line item carries billed, effective, list, contracted, public on-demand cost, the public equivalent of billed and effective cost before discounts, and a rate for each, so you can measure savings and amortized cost without building your own calculations. To add the columns, select Include standardized cost and rate columns when you create or edit a CUR 2.0 export. In Cost Explorer, choose the newly introduced cost types under Advanced options to see the same costs.

In a recent development, standardized cost and rate columns are available at no additional charge in all AWS Regions except the AWS GovCloud (US) Regions and the China Regions. To learn more, see the CUR 2.0 data dictionary and the user guide for Cost Explorer.
