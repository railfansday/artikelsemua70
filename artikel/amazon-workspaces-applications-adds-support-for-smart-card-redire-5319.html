Amazon WorkSpaces Applications adds support for smart card redirection

🌐 Source: Amazon • 📅 17 Nov 2026 • ⏱️ 1 min read (243 words, 📖 Standard)
💡 Key Takeaways
  • Amazon WorkSpaces Applications now supports smart card redirection on single-session and multi-session fleets, so owners can access the smart card connected to their local device from applications inside their streaming session.
  • Administrators can turn smart card sign-in for Active Directory and smart card redirection on or off independently for each stack.
  • These capabilities are available today in all AWS commercial and AWS GovCloud (US) regions that offer WorkSpaces Applications.

Amazon WorkSpaces Applications now supports smart card redirection on single-session and multi-session fleets, so owners can access the smart card connected to their local device from applications inside their streaming session. It also extends smart card sign-in, previously limited to single-session fleets, to multi-session fleets. This launch helps public sector, healthcare, and other regulated organizations that use Common Access Card (CAC) or Personal Identity Verification (PIV) cards run those workflows on multi-session fleets.

Administrators can turn smart card sign-in for Active Directory and smart card redirection on or off independently for each stack. Smart card sign-in lets consumers sign in to domain-joined streaming instances with their smart card instead of a password, while redirected smart cards support in-session authentication, digital signing, and email encryption. For example, a government agency can move CAC users from single-session to multi-session fleets and keep CAC sign-in.

These capabilities are available today in all AWS commercial and AWS GovCloud (US) regions that offer WorkSpaces Applications.

Industry observers note that to get started, turn on either setting under User settings for your stack, use a Windows image with the latest WorkSpaces Applications agent, and connect with the WorkSpaces Applications client for Windows. Upcoming stacks have both settings turned off by default, and existing stacks that use smart card redirection keep it turned on. To learn more, see Create a stack in the Amazon WorkSpaces Applications Administration Guide, or visit the Amazon WorkSpaces Applications product page.
