This lightweight Linux distro ditched KDE Plasma – and it’s better than ever

Sources indicate that kaOS 2026.11 is a free, systemd-free Linux distribution that delivers outstanding desktop performance, even on older computers with as little as 2GB of RAM. I recently wrote about KaOS Linux dropping KDE Plasma as its default desktop environment. At that time, KaOS retained KDE Plasma in its repositories, so people could, if they so chose, install the more familiar KDE Plasma DE. In a recent development, however, the KaOS team decided to remove KDE Plasma from the repositories, making the “K” in KaOS no longer necessary.

With KDE Plasma no longer an option, does the distro still stand up to its previous incarnations? Let’s find out.

Sources indicate that for those who’ve never heard of Niri, it’s a lightweight tiling window manager that takes a very different approach to managing windows. Instead of the traditional tiling window manager approach of placing apps in the most logical, convenient location on the display (which can lead to smaller and smaller windows as you open more apps), Niri goes with a never-ending horizontal strip that can be scrolled.

Sources indicate that that pattern continues as you open more apps, with each succeeding app opening to the right of the previous one. As each app opens, you can drag it to the right or the left (via the title bar) to move the strip along. Find the app you want and use it. Niri presents a very elegant solution to multitasking: It’s simple to use and fast.

But what has changed in KaOS (other than the removal of KDE Plasma from the repositories) since I last reviewed it? This fresh iteration is 2026.11, which was recently released, and the changes are subtle but notable.

The first thing I noticed was that KaOS now uses Noctalia, which is a native Wayland desktop shell. This shell provides the desktop layer for the Wayland compositor, a layer that consists of things like title bars, the launcher, notifications, the lock screen, and wallpaper.

Industry observers note that there was one single reason why KaOS switched to Noctalia (which also informs us as to why the developers dropped KDE Plasma from the repositories). Because KaOS shrugged off systemd as its init system, a newly introduced window shell had to be used. It’s not that the KDE Plasma KWin window manager requires systemd, but since KDE Plasma does use systemd as a manager for KWin, it became a no-brainer.

You also get a ton of settings to play with, so much so that it can be a bit overwhelming.

Noctalia v5 is built directly on Wayland and OpenGL ES, and the end results are far faster and far smoother than what I’d previously experienced with KaOS. To me, that’s the big change because the speed of KaOS 2026.11 blows away the last release I’d tested. Animations are like butter, and there’s zero screen tearing or stuttering as you drag the app strip from side to side. This is macOS-level smoothness, and I’m all for it.

Industry observers note that another change in KaOS 2026.11 is the display manager, which is now greetd (with tuigreet). The greetd display manager integrates with seatd (a seat management daemon for Linux that mediates access to shared devices). In addition to tuigreet (which is a console-based greeter), KaOS also has the option to use noctalia-greeter, which is based on greetd with the addition of the GUI element. The one caveat is that noctalia-greeter is not quite as complete as tuigreet, so use it at your own discretion.

There are also a few new packages that have been added into the mix, including dex (which brings full XDG autostart support for a non-systemd system), kss (a KConfig module application to adjust settings for KDE applications), Zig and libghostty (to enable early testing of KDE Plasma’s new GPU-supported terminal emulator, kwi), and Croeso (the new onboarding app). The android-tools package has been re-added.

Another bit of good news is that KDE apps are still available to install from the KaOS repositories, even without KDE Plasma. I tested this theory by installing KMail, which worked perfectly.

As I mentioned, these changes had to take place as KaOS remains a systemd-free distribution, which doesn’t exactly work well with the latest releases of KDE Plasma. For the users, it matters because KaOS now feels like it belongs on the desktop; it runs incredibly well, feels rock solid, and levels up multitasking with a simple workflow that will have you wondering why no one had thought of it before (thank you, Niri).

Also: A super fast distro for anyone ready to move beyond beginner Linux.

According to recent reports, more than anything (for me), the fresh KaOS runs so smoothly. I’ve used other distros with Niri (such as Pond), and none of them can compete with the performance and smoothness of KaOS. For me, KaOS unseats every lightweight Linux distribution to become the best option for older machines.

To run KaOS, all you need is a 64-bit x86 CPU and 2GB of RAM (4GB being the recommended minimum). That’s chump change in the modern world. To be fair, I installed KaOS on a desktop machine with an Intel Core Ultra 9 CPU and 32GB of RAM, but I have experienced the OS on machines with as little as 3GB of RAM and only two CPU cores, and it still holds up.

It has been revealed that if you’re looking for a systemd-free Linux distribution with a unique desktop UI and outstanding performance, do not overlook KaOS 2026.11. You can download the ISO for free from the official KaOS download site.
