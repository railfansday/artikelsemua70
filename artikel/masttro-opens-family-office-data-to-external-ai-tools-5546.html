Masttro opens family office data to external AI tools

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Masttro, a global platform serving as the system of record for complex wealth reporting, has rolled out a Model Context Protocol (MCP) Server alongside a fresh Developer Portal.

The launch gives family offices, wealth owners and advisors a way to use compatible outside AI applications with their financial information.

The MCP server sits on top of the company’s current API framework. It lets eligible clients link chosen wealth data to third-party AI environments through an open interoperability standard, so they are not tied to any one AI vendor. Clients must authorise any connection, and access is read-only. It covers data such as holdings, transactions and performance, as well as the entity and ownership structures held in Masttro.

According to recent reports, this context matters most for families whose wealth spans several institutions, jurisdictions, asset classes and legal entities. Masttro does more than consolidate financial data. It also records how assets connect to ownership entities, trusts and beneficiaries, which gives AI-supported financial analysis a broader base to work from.

The launch was built around three architectural priorities. The first is richer context: compatible applications can draw on selected holdings, transactions, performance figures and ownership links, within the limits of the authenticated user’s permissions.

According to recent reports, the second is client control. MCP access is switched off by default and only works once a client explicitly activates and authorises it. Client administrators decide who has access and can withdraw permissions or turn off connectivity entirely. Because the server is read-only, outside applications cannot change Masttro records, start transactions or write data back.

It has been revealed that the third is defined security boundaries. Masttro’s existing authentication, authorisation and security controls apply to all data accessed through MCP. After data reaches an authorised AI environment, the client’s chosen provider is responsible for how it is processed, stored, retained and protected.

The MCP offering sits alongside Masttro Intelligence, the firm’s own model-agnostic AI environment. Masttro Intelligence handles advanced analysis, document processing and operational efficiency. It keeps AI orchestration, permissions and governance inside Masttro, so clients do not need to send their underlying wealth data to outside AI tools. Clients can therefore choose between governed in-platform AI and optional, client-authorised links to external applications.

The Developer Portal gives client technical teams and developers API and MCP documentation, authentication guidance, setup instructions and worked integration examples.

Masttro co-founder Domingo Viesca mentioned, “As AI models continue to evolve, the strategic value lies not in any individual model, but in the quality, context, and governance of the information they can access.

According to recent reports, “Masttro provides that foundation for complex wealth. Our MCP Server gives clients the flexibility to authorize external AI tools when appropriate, while maintaining control over access to their information. Masttro Intelligence remains our integrated environment for delivering advanced AI capabilities within our own security and governance framework.”.
