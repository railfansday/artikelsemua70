AWS Lambda now provides cost optimization recommendations for Event Functions

Recent findings suggest that AWS Lambda now provides cost optimization recommendations for Event Functions in AWS Trusted Advisor. These recommendations identify on-demand functions where moving to Lambda Managed Instances (LMI) is estimated to reduce costs, and provide configuration guidance for running on LMI. With these recommendations, you can lower your Lambda costs by focusing your efforts on the functions with the greatest estimated savings.

Industry observers note that LMI lets you run Lambda functions on Amazon EC2 instances while maintaining the operational simplicity of Lambda. With LMI, you can access specialized compute configurations and drive cost efficiency through EC2 pricing options such as Savings Plans and Reserved Instances, without managing infrastructure. Previously, to determine whether a function was a good fit for LMI, you had to analyze its invocation patterns, estimate LMI costs, and select the right instance type and memory-to-vCPU ratio yourself. This manual process added overhead and delayed savings. With this launch, Lambda automatically analyzes the invocation patterns, duration, and resource utilization of your high-volume Event Functions and recommends those where LMI is estimated to reduce costs. Estimates are based on a simulation of each function's invocation patterns, using public Lambda pricing and Amazon EC2 On-Demand pricing. Each recommendation includes the function ARN, the recommended EC2 instance type and memory-to-vCPU ratio, the estimated current cost, the estimated LMI cost, and the estimated savings. You can use the recommended configuration to run a function on LMI without sizing it yourself and realize cost savings sooner.

These recommendations are available in the following AWS Regions: US East (N. Virginia), US West (Oregon), Europe (Ireland), and Europe (Milan). Customers with eligible AWS Support aims can access them in the Trusted Advisor console alongside other cost optimization checks. To learn more, visit the AWS Lambda Developer Guide, the AWS Trusted Advisor User Guide, and the AWS Lambda pricing.
