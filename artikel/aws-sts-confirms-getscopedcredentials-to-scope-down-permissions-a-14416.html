Sources indicate that AWS Security Token Service (AWS STS) introduces GetScopedCredentials, a fresh API that lets you scope down the permissions of existing temporary security credentials. With GetScopedCredentials, you can give your agents, sub agents and workloads their own set of credentials with only the permissions they need.

It has been revealed that you can call GetScopedCredentials with the temporary security credentials you already use to reduce permissions, session duration, or both. The resulting credentials preserve the caller's original identity, and permissions and session duration are monotonically narrowed so they never exceed those of the caller. Access to the API is controlled with IAM policies, and each call is logged to AWS CloudTrail for traceability. These capabilities make it easier to scope down permissions at runtime without changing how you manage identities.

GetScopedCredentials is available in all AWS commercial Regions, AWS GovCloud (US) Regions, AWS European Sovereign Cloud (Germany) Regions and China Regions. To get started, see the GetScopedCredentials API reference and Permissions for GetScopedCredentials.
