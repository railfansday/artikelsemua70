Amazon EVS launches support for r7i.metal instances, external principal storage, and an Agent Skill

According to recent reports, today, we are announcing that Amazon Elastic VMware Service (Amazon EVS) now supports the r7i.metal-24xl and r7i.metal-48xl Amazon Elastic Compute Cloud (EC2) bare metal instance types for VMware Cloud Foundation (VCF) 9.x deployments. EC2 r7i instances are memory optimized, with custom 4th Generation Intel Xeon Scalable (Sapphire Rapids) processors, and designed to be used with external storage. With these instances possessing no local NVMe disks, Amazon EVS now supports VCF external principal storage with solutions such as Amazon FSx for NetApp ONTAP. With this launch, you can use the Amazon EVS Deployment Orchestrator (EDO) within the Solutions for EVS GitHub repository to fully automate the end-to-end deployment and configuration of your VCF 9.x environment on EVS.

With this release, you now have more options for running VMware-based Virtual Machines (VM) in your Amazon VPC - while keeping the same tools, skills, and operational processes, and full control of your architecture, configuration, and lifecycle of your environment.

Industry observers note that we are also launching a fresh Amazon EVS Agent Skill, which gives your AI Agents context to help you plan, deploy, and operate your Amazon EVS environments - from answering questions and recommending designs to generating blueprints and driving deployments with EDO. To get started, point the AI agent of your choice to the EVS Agent Skill file in the latest release of the EVS GitHub repository.

This release is available in all regions where Amazon EVS is offered. To learn more about Amazon EVS, visit the product detail page and the user guide.
