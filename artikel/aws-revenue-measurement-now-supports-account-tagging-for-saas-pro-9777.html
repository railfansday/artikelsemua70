AWS Revenue Measurement now supports Account Tagging for SaaS Products

🌐 Source: Amazon • 📅 19 Nov 2026 • ⏱️ 1 min read (202 words, 📖 Standard)

  • Account Tagging for SaaS Products is available for products with a SaaS listing on AWS Marketplace.

Recent findings suggest that AWS Revenue Measurement (previously Partner Revenue Measurement) provides measurement of AWS consumption driven by Partner solutions. Today, AWS introduces Account Tagging for SaaS Products for AWS Revenue Measurement. Partners can now measure the AWS revenue impact of their SaaS solutions by tagging the AWS accounts that host them, instead of tagging individual resources.

It has been revealed that until now, Partners with SaaS listings measured that impact through Resource Tagging, User Agent strings, or AWS Marketplace Metering. With Account Tagging for SaaS products, a Partner uses AWS Organizations to tag partner-owned member accounts dedicated to a single SaaS product. The tag key is aws-apn-id- and the tag value is pc:. AWS Revenue Measurement then attributes all eligible AWS consumption in each tagged account to that product.

Account Tagging for SaaS Products is available for products with a SaaS listing on AWS Marketplace. Each tagged account must be dedicated to one product. Partners whose products share an account can continue to use Resource Tagging, User Agent string, or Identity Tagging. AWS Revenue Measurement is generally available in all commercial regions. To learn more about implementing AWS Revenue Measurement, review the onboarding guide for more information.
