Amazon S3 increases the read request rate for general purpose buckets by up to 2x

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (111 words, ⚡ Quick Read)
💡 Key Takeaways
  • Amazon S3 now supports at least 11,000 GET/HEAD requests per second, up from 5,500, for general purpose buckets.
  • It has been revealed that with this higher request rate, you can retrieve data faster for read-intensive workloads such as machine learning training, data analytics, and data transfers.
  • This increase applies automatically to your existing read requests in all AWS Regions, with no changes required to your applications and at no additional charge beyond standard S3 request pricing.

Amazon S3 now supports at least 11,000 GET/HEAD requests per second, up from 5,500, for general purpose buckets.

It has been revealed that with this higher request rate, you can retrieve data faster for read-intensive workloads such as machine learning training, data analytics, and data transfers. To maximize throughput, distribute your requests across multiple prefixes so that S3 can scale each one independently.

This increase applies automatically to your existing read requests in all AWS Regions, with no changes required to your applications and at no additional charge beyond standard S3 request pricing. To learn more, visit the Amazon S3 user guide and the S3 product page.
