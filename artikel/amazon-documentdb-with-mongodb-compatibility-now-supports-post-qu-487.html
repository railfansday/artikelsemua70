📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

In a recent development, amazon DocumentDB (with MongoDB compatibility) 8.0.3 adds hybrid post-quantum key exchange for TLS, wildcard indexes, the $unionWith aggregation stage, and latest change stream events. Post-quantum TLS protects data in transit from traffic that is recorded today and decrypted later with a quantum computer. The new MongoDB APIs let you move more MongoDB workloads to Amazon DocumentDB without changing application code.

Post-quantum TLS: TLS 1.3 connections use hybrid key exchange based on the Module-Lattice-Based Key-Encapsulation Mechanism (ML-KEM) when the client supports it. Other clients keep using classical key exchange. Two new Amazon CloudWatch metrics, TLSHandshakesClassical and TLSHandshakesPostQuantum, count the handshakes of each type.

Wildcard indexes: index every field, or every field under a path, to query documents with dynamic schemas.

It has been revealed that aggregation: $unionWith combines results from multiple collections in one pipeline. $lookup and $graphLookup work in views, and correlated $lookup sub-pipelines accept $unionWith and $facet.

Change streams: dropIndex() and dropIndexes() now emit dropIndexes events.

Compression metrics: collStats and stats() report per-collection input bytes, output bytes, and compression ratio.

Industry observers note that amazon DocumentDB 8.0.3 is available in all AWS Regions where Amazon DocumentDB is offered. To learn more, see the Amazon DocumentDB Developer Guide.
