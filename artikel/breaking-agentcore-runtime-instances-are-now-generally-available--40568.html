Breaking: AgentCore runtime instances are now generally available in the AWS GovCloud (US-West) Region

🌐 Source: Amazon • 📅 23 Nov 2026 • ⏱️ 1 min read (162 words, 📖 Standard)
💡 Key Takeaways
  • Industry observers note that amazon Bedrock AgentCore runtime instances are now available in the AWS GovCloud (US-West) Region.
  • With runtime instances, teams in AWS GovCloud (US) can choose GPU-accelerated, memory-optimized, or compute-optimized instance types for their agents and run agent sessions of up to 14 days.
  • You are charged for the management of the compute provisioned, in addition to your Amazon EC2 costs.

Industry observers note that amazon Bedrock AgentCore runtime instances are now available in the AWS GovCloud (US-West) Region. Runtime instances run your agents on Amazon EC2 instances in your own account, while AgentCore handles provisioning, patching, scaling, and lifecycle management.

With runtime instances, teams in AWS GovCloud (US) can choose GPU-accelerated, memory-optimized, or compute-optimized instance types for their agents and run agent sessions of up to 14 days. Agent instances, storage volumes, and session data stay in the AWS GovCloud (US-West) Region, which helps public sector organizations and their partners meet data residency and compliance requirements. Runtime instances work alongside the default serverless, microVM-based AgentCore runtime, so you can pick the right compute for each agent without changing how you deploy or invoke it.

You are charged for the management of the compute provisioned, in addition to your Amazon EC2 costs. To get started, visit AWS News Blog or AgentCore documentation. To learn about pricing, visit AgentCore pricing.
