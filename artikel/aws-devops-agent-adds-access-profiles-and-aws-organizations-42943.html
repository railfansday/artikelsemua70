AWS DevOps Agent now gives you more ways to govern and control your AWS DevOps Agent instances.

With the newly introduced Access Profiles feature you can link IAM IDC customers in your Agent Spaces to specific permission sets. For example, you can use Access Profiles to limit the ability to create or revision skills and memories to a select set of users. AWS Organizations support allows you to more easily configure your Agent Space's AWS account access permissions by automatically aligning accounts in organizations with your Agent Spaces.

For the list of AWS Regions where AWS DevOps Agent is available, see the supported Regions table.
