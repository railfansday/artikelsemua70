Industry News: I’ve been using the MS Word clone WordCraft for a month – and I love it even more now

Back in October, I wrote about WordCraft, the open-source clone of MS Word. After writing that piece, I assumed that I’d go back to writing in Google Docs, but I reconsidered. Why? Privacy. I don’t want Google to dip its fingers into the well of my creativity, so I initially decided to write all of my books locally.

And now that I have my own writing app (which is already available for Linux and will be available soon for both MacOS and Windows), I don’t even need a word processor for first drafts. I do, however, need it for the editing process.

Also: Someone made a free Photoshop clone – so I had to try it on Linux.

In light of my review of WordCraft, I thought I’d stick with it and see how I felt about the app after a month or so. That month has passed, and I’m still using WordCraft.

Industry observers note that I won’t use the Windows OS, and if given the opportunity, I will always choose open-source software over proprietary software, and I have a very good reason for that. Without Windows, using MS Word is a challenge. Yes, there’s Wine, but that’s an extra layer of complication. And, of course, there’s Office365, but I want nothing to do with third-party cloud storage or services.

It has been revealed that soon after I wrote the piece about WordCraft, there was concern about it being nothing more than a vehicle for malicious code. Because the app is open-source, I was able to clone the source from its GitHub repository, add it to a upcoming VS Code workspace, and have GitHub Copilot automatically scan the source for bugs, errors, and malicious code.

According to recent reports, the scan came up clean. I ran it again, and again, it came up clean.

Also: I tried the free PowerPoint clone on Linux – it beats LibreOffice and Google Slides.

After three attempts, I decided WordCraft was as safe to use as any software, so I continued using it. And although it was still in early development, I’d already found it to be more than stable enough for my needs.

The other thing about using this open-source clone is that updates come faster and more frequently than MS Word. I’m not saying the updates are daily, but I have found them to be almost weekly. And with each upgrade, the software runs even better.

At this point, I find WordCraft to already be better than most word processor apps I’ve used on both Linux and MacOS.

After using WordCraft for a month, I’ve found a few key aspects (for me) that are marked improvements over other (similar) apps.

It has been revealed that first off, WordCraft is stupid fast. No other word processor (regardless of OS) opens this promptly. Seriously…click on the launcher and WordCraft is instantly ready to go. Given how much I write, speed is an key factor. The opening and closing of the app isn’t the only zippy aspect of WordCraft; the UI responds instantly, saving is immediate, and closing the app happens as fast as you can click.

Also: I tried the free Adobe Acrobat clone – and finally have a pro PDF editor on Linux.

Recent findings suggest that I’ve come to appreciate its collaboration features between users who work with MS Office and me. I’ve used nearly every word processor on the market, and the only app that can top WordCraft’s collaboration with MS Office is MS Office. Whether it’s text formatting, page layout, track changes, or comments, WordCraft does it all to a T. Not having to deal with the frustration of constantly reformatting or structuring a document simply because the tool I use can’t seem to properly interpret what MS Office does is a breath of fresh air. That’s not to place the blame on other apps, but we all know that where MS Word goes, other apps must follow.

In a recent development, I’ve imported full book manuscripts (in .docx file format) and had zero problems. Even manuscripts with hundreds of comments and track changes didn’t cause a single problem with WordCraft. And as far as the review tools, no other non-MS Office app can hold a candle to what WordCraft offers. In fact, it was the poorly designed review tools (track changes and comments) in LibreOffice that sent me packing from that app.

Sources indicate that wordCraft is also reliable. I’ve lost so much work to Apple Pages that I eventually deemed it absolutely off limits. This comes as a shock, given how young WordCraft is. This app has existed for about as long as I’ve been using it, and I already trust it more than other apps I’ve used. Since I adopted WordCraft, I haven’t lost a single bit of work.

It has been revealed that in my original review, I noted that there was a delay in typing in WordCraft. Although there is still a slight delay (we’re talking milliseconds), it’s much better than it was when I first used the app.

If there were two features that I could add to WordCraft, it would be user-customizable themes and Grammarly integration. Although Grammarly doesn’t have a strict ban on open-source integration, there are problems with technical UI requirements, developer tools that are deprecated, and licensing issues that cause problems with integration. Maybe, someday in the future, WordCraft will achieve that integration.

It has been revealed that you bet. Until something better comes along (which I don’t expect), WordCraft is my default word processor. No, I will not be using WordCraft for novels (that’s where Quillwriter comes into play), but for everything else, you can bet that WordCraft will continue to be my go-to for tech writing and other non-fiction work.
