Industry News: Amazon S3 adds post-quantum TLS key exchange support to additional S3 endpoints

🌐 Source: Amazon • 📅 17 Nov 2026 • ⏱️ 1 min read (162 words, 📖 Standard)
💡 Key Takeaways
  • Amazon S3 adds post-quantum TLS (PQ-TLS) key exchange support to S3 Vectors and AWS PrivateLink for Amazon S3 interface endpoints.
  • S3 Vectors endpoints and PrivateLink interface endpoints now support Module-Lattice-Based Key-Encapsulation Mechanism (ML-KEM), one of the National Institute of Standards and Technology (NIST) standardized post-quantum cryptographic algorithms.
  • In a recent development, PQ-TLS key exchange for S3 Vectors and AWS PrivateLink for S3 is supported at no additional cost in all AWS Regions.

Amazon S3 adds post-quantum TLS (PQ-TLS) key exchange support to S3 Vectors and AWS PrivateLink for Amazon S3 interface endpoints. This extends the post-quantum cryptography support already available on regional S3, S3 Tables, and S3 Express One Zone endpoints.

S3 Vectors endpoints and PrivateLink interface endpoints now support Module-Lattice-Based Key-Encapsulation Mechanism (ML-KEM), one of the National Institute of Standards and Technology (NIST) standardized post-quantum cryptographic algorithms. PQ-TLS key exchange is available to all clients configured to use the ML-KEM key exchange algorithm. S3 Vectors and PrivateLink endpoints automatically negotiate the strongest key exchange that your client software supports, so clients that support ML-KEM receive the benefits of PQ-TLS key exchange without any changes to your applications or endpoint configuration.

In a recent development, PQ-TLS key exchange for S3 Vectors and AWS PrivateLink for S3 is supported at no additional cost in all AWS Regions. To learn more about PQ-TLS support in S3, visit the Amazon S3 User Guide.
