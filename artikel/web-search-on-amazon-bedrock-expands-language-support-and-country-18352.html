Web Search on Amazon Bedrock, the tool that grounds AI agents and applications in cited, current web information, now supports five new languages, plus non-US English, on Amazon Bedrock AgentCore and Amazon Bedrock: Spanish, French, German, Italian, and Japanese. Agents serving users in these languages get results that draw on local-language sources.

Sources indicate that we are also introducing a new optional country field that biases results toward sources from a specific country - just pass an ISO 3166-1 alpha-2 country code, such as “JP” or “DE”. This is useful for agents that serve users in multiple countries, for questions whose answer depends on the user's actual or preferred location (e.g., local regulations, prices or public officials), and for surfacing regional sources.

Sources indicate that both the expanded language support and the optional  country field are available today in every Region where Web Search is offered: US East (N. Virginia), US East (Ohio), US West (Oregon), Asia Pacific (Sydney), Asia Pacific (Tokyo), and Europe (Ireland) for Web Search on Amazon Bedrock AgentCore, and US Regions for Web Search on Amazon Bedrock. Queries are processed in the Region you call, helping organizations meet data residency requirements. Existing customers get the latest language capabilities automatically, with no code changes, and pricing is the same in every language.

To get started with Web Search on Amazon Bedrock, checkout the developer guide and the web search product page.
