Computing Weighted Set Covers with Heterogeneous Stochastic Oracles: Deadline-Constrained Token Complexity

🌐 Source: Arxiv • 📅 23 Nov 2026 • ⏱️ 1 min read (253 words, 📖 Standard)

arXiv:2611.26656v1 Announce Type: cross Abstract: We study computation in which a probabilistic Turing machine (PTM) uses AI systems, abstracted as heterogeneous stochastic oracles (HSOs), to solve Weighted Set Cover. A pilot study reveals that an LLM can outperform weighted greedy. HSOs differ in capabilities, response distributions, latencies, and token costs. We study how the PTM selects HSOs to obtain, by a deadline and with a required success probability, a full cover satisfying a prescribed weight threshold, and we analyze expected token cost. For queries requesting full covers, assuming independent call successes and uninformative failures, we characterize by linear programming the minimum expected token cost for every feasible success probability. An optimal policy randomizes over at most two preselected sequences of oracle batches. Among policies attaining maximum success probability, the expected cost reduction of two-batch selection relative to querying all oracles in one batch is nonnegative and submodular. We construct an FPTAS for near-optimal cost reduction under heterogeneous response-time bounds. Computing an optimal two-batch selection is NP-hard but admits a pseudopolynomial algorithm for positive integral expected token costs. For partial-cover responses, the PTM combines returned sets across batches and turns. Once their union covers the universe, it verifies total weight directly or obtains a guarantee from LP-dual tests on retained partial covers. We give one-turn probability, token-cost, and hardness results and adaptive token-cost bounds under per-batch assumptions. A constructed instance shows that residual-guided querying can reduce expected token cost by a factor linear in the number of possible residual subproblems.
