Sources indicate that starting today, Amazon Elastic Compute Cloud (Amazon EC2) M9g instances, powered by AWS Graviton5 processors, are available in US West (N. California), Canada (Central), South America (São Paulo), and Asia Pacific (Seoul) regions. AWS Graviton5 processors are the fifth generation of custom-designed CPUs, delivering the best price performance for memory-intensive workloads running on Amazon EC2.

Recent findings suggest that M9g instances deliver up to 25% better performance compared to AWS Graviton4-based M8g instances. They are up to 30% faster for databases. These instances are built on the sixth-generation AWS Nitro System and are the first to feature the Nitro Isolation Engine, harnessing formal verification to provide mathematical assurance that customer workloads are isolated from each other and AWS operators, pioneering a fresh standard for mathematically proven cloud security.

M9g instances are ideal for workloads such as open-source databases, in-memory caches, major data analytics, and memory-intensive applications.

In a recent development, M9g instances are available for purchase in these four regions via Savings Plans, On-Demand, Spot instances, Dedicated instances, or Dedicated hosts. Level up your compute with AWS Graviton and get started today.
