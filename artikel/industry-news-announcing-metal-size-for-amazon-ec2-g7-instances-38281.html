It has been revealed that today, AWS unveils the general availability of the metal size for Amazon Elastic Compute Cloud (Amazon EC2) G7 instances, accelerated by NVIDIA RTX PRO 4500 Blackwell Server Edition GPUs. G7 instances deliver up to 4.6x AI inference performance and up to 2.1x graphics performance compared to G6.

Customers can use the metal size of G7 instances to run physical AI simulations, deploy AI agent sandboxes, and accelerate graphics workloads that need direct access to bare metal infrastructure. G7 metal instances enable customers to run specialized workloads that require a custom virtualization stack, hypervisor-level GPU drivers, or licensing-restricted applications. The metal size of G7 instances feature 8 NVIDIA RTX PRO 4500 Blackwell Server Edition GPUs with 32 GB of memory per GPU and custom Intel Xeon 6 processors. They support 192 virtual CPUs (vCPUs), 768 GiB of system memory, and 700 Gbps of Elastic Fabric Adapter (EFA) networking bandwidth.

The newly introduced metal size is available in the AWS US East (N. Virginia) Region. You can purchase G7 metal instances as On-Demand Instances, Spot Instances, or as part of Savings Plans.

To get started, use the AWS Management Console, AWS Command Line Interface (AWS CLI), or AWS SDKs. To learn more, visit the G7 instance page.
