Amazon Cognito now supports AWS Secrets Manager for app client secrets

🌐 Source: Amazon • 📅 19 Nov 2026 • ⏱️ 1 min read (190 words, 📖 Standard)
💡 Key Takeaways
  • Amazon Cognito now integrates with AWS Secrets Manager, so you can store and manage your user pool app client secrets in Secrets Manager.
  • Sources indicate that with this integration, you can leverage Secrets Manager for capabilities including rotation, access control with AWS Identity and Access Management (IAM) policies, and encryption with an AWS managed key or your own AWS Key Management Service (AWS KMS) customer managed key.
  • This integration is available in all AWS Regions where Amazon Cognito and AWS Secrets Manager are available, except AWS European Sovereign Cloud (Germany).

Amazon Cognito now integrates with AWS Secrets Manager, so you can store and manage your user pool app client secrets in Secrets Manager. Amazon Cognito helps you implement secure sign-in and access control for owners, AI agents, and microservices in minutes. An app client secret authenticates your application to Cognito. Previously, you had to manage and rotate these secrets in Cognito directly.

Sources indicate that with this integration, you can leverage Secrets Manager for capabilities including rotation, access control with AWS Identity and Access Management (IAM) policies, and encryption with an AWS managed key or your own AWS Key Management Service (AWS KMS) customer managed key. This can help with periodic credential rotation or compliance requirements; this also helps with keeping secrets out of the console. You can enable this integration for either a new or an existing app client, and disable it at any time.

This integration is available in all AWS Regions where Amazon Cognito and AWS Secrets Manager are available, except AWS European Sovereign Cloud (Germany). Standard AWS Secrets Manager charges apply. To learn more, see the Amazon Cognito Developer Guide for instructions.
