Tech Report: Now Firefox can select which sites use its VPN, and clear your browsing history with one click

🌐 Source: The Verge • 📅 24 Nov 2026 • ⏱️ 1 min read (140 words, ⚡ Quick Read)
💡 Key Takeaways
  • In a recent development, mozilla released Firefox 161 on Tuesday with a fresh setting you can use to choose which pages automatically open with the browser’s VPN active.
  • Tuesday’s Firefox patch also adds an option for creating a keyboard shortcut for copying your current tab’s URL, and brings its “read aloud” option in Reader Mode to the Android version of Firefox.

In a recent development, mozilla released Firefox 161 on Tuesday with a fresh setting you can use to choose which pages automatically open with the browser’s VPN active. Using the “Manage VPN rules” option in Firefox’s VPN panel, you can set it to “always on” or “always off” for specific sites, so you don’t have to toggle it manually every time you visit certain pages.

Tuesday’s Firefox patch also adds an option for creating a keyboard shortcut for copying your current tab’s URL, and brings its “read aloud” option in Reader Mode to the Android version of Firefox. Alongside the update, Mozilla states Firefox is also now available directly through the Play Store on cars with Google built-in.
