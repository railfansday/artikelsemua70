Amazon CloudFront is now available in the AWS European Sovereign Cloud

🌐 Source: Amazon • 📅 23 Nov 2026 • ⏱️ 1 min read (225 words, 📖 Standard)

  • To get started, sign in to your AWS European Sovereign Cloud account and create a distribution in the CloudFront console.

Amazon CloudFront is now available in the AWS European Sovereign Cloud. Organizations with strict EU sovereignty requirements can now deliver websites, applications, and APIs with the performance, security, and scale of CloudFront, all within the EU. Until now, customers had to build and run their own delivery and TLS termination infrastructure to keep traffic and data inside the EU.

Industry observers note that with CloudFront in the AWS European Sovereign Cloud, content delivery, TLS termination, logs, and customer configuration stay within the European Sovereign Cloud boundary. The AWS European Sovereign Cloud is physically and logically separate from other AWS Regions, and only EU-resident personnel operate it. This helps governments, healthcare, financial services and other regulated industries meet data residency and operational sovereignty requirements without trading away performance and scale. Customers use the same CloudFront APIs and console experience they already know making it easy to transfer over existing deployments and automations. If you initiative to run media streaming or other high-volume workloads, contact your AWS account team and we can help you find the right solution, including options in AWS commercial Regions.

To get started, sign in to your AWS European Sovereign Cloud account and create a distribution in the CloudFront console. To learn more about available features and pricing, see the CloudFront Developer Guide and CloudFront pricing page in ESC.
