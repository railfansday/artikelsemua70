Industry News: Second-generation AWS Outposts racks now supported in the AWS Asia Pacific (Osaka)

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (136 words, ⚡ Quick Read)
💡 Key Takeaways
  • Second-generation AWS Outposts racks are now supported in the AWS Asia Pacific (Osaka) Region.
  • Organizations of every size, from startups to enterprises to public sector agencies, can now order Outposts racks connected to this newly supported Region to optimize for latency and data residency needs.
  • Recent findings suggest that to learn more about second-generation Outposts racks, read the AWS Outposts blog post and user guide.

Second-generation AWS Outposts racks are now supported in the AWS Asia Pacific (Osaka) Region. Outposts racks extend AWS infrastructure, AWS services, APIs, and tools to virtually any on-premises data center or colocation space for a truly consistent hybrid experience.

Organizations of every size, from startups to enterprises to public sector agencies, can now order Outposts racks connected to this newly supported Region to optimize for latency and data residency needs. This regional expansion provides additional flexibility in the number of AWS Regions that customers' Outposts can connect to.

Recent findings suggest that to learn more about second-generation Outposts racks, read the AWS Outposts blog post and user guide. For the latest list of countries and territories and the AWS Regions where second-generation Outposts racks are supported, see the AWS Outposts FAQs page.
