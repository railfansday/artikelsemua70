Latest Update: AWS DevOps Agent adds agent sandboxes

🌐 Source: Amazon • 📅 20 Nov 2026 • ⏱️ 1 min read (253 words, 📖 Standard)
💡 Key Takeaways
  • Sources indicate that AWS DevOps Agent now gives you more ways to make your agents smarter.
  • It has been revealed that most teams already have the scripts that answer their hardest questions.
  • It has been revealed that with this launch AWS DevOps Agent can also write and execute its own scripts.

Sources indicate that AWS DevOps Agent now gives you more ways to make your agents smarter. Sandboxes give you the ability to write skills that include scripts your agent can run, and a way for agents themselves to write and run scripts that make them more efficient.

It has been revealed that most teams already have the scripts that answer their hardest questions. Without a sandbox, the best you can do is describe those scripts in a skill and hope the agent rebuilds them correctly. With a sandbox, you put the script in the skill. The agent runs your team's own diagnostic script in its sandbox and spends its reasoning on what the numbers mean.

It has been revealed that with this launch AWS DevOps Agent can also write and execute its own scripts. For example, with a sandbox the agent can write a script that runs four log queries in parallel, one for each step of a request flow, join them, time every step, and replay the same analysis across earlier request flows. Without sandboxes agents rely on tool calls to APIs to perform log and metric analysis which can be cumbersome and slow. With sandboxes and the ability to write and execute scripts they can perform this kind of analysis much more efficiently.
