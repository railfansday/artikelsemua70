When Code Works but the License Doesn't: Evaluating License Constraint Handling in Coding Agents

🌐 Source: Arxiv • 📅 20 Nov 2026 • ⏱️ 1 min read (153 words, 📖 Standard)

In a recent development, arXiv:2611.23299v1 Announce Type: cross Abstract: Coding agents increasingly undertake repository-level development, including dependency selection, source modification, and software deployment. However, existing evaluations prioritize functional success over licensing correctness and commercial suitability. We investigate whether agents recognize and preserve software-license constraints when developing proprietary software. Experiments across multiple agents examine permissive and copyleft licenses, missing licensing information, transitive dependencies, source modification, dual licensing, vendoring, and distribution contexts. Agent traces, repository changes, and final artifacts are evaluated against licensing ground truth. Results reveal a persistent gap between functional and licensing correctness. Agents can successfully build and test software while overlooking licensing constraints involving provenance, authorization, and distribution. Better outcomes emerge when licensing information translates into engineering actions such as dependency substitution, architectural changes, and release gating. We argue that licensing in agentic development requires contextual constraint recognition and preservation across the software lifecycle, not merely license classification.
