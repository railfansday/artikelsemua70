Aurora PostgreSQL with express configuration now supported in CloudFormation

🌐 Source: Amazon • 📅 13 Nov 2026 • ⏱️ 1 min read (155 words, 📖 Standard)
💡 Key Takeaways
  • Aurora PostgreSQL now supports express configuration in AWS CloudFormation for infrastructure as code deployment.
  • Aurora PostgreSQL clusters created with express configuration allow you to create and query an Aurora serverless database in seconds.
  • Recent findings suggest that the CloudFormation support is available in all AWS Regions where Aurora PostgreSQL with express configuration is offered.

Aurora PostgreSQL now supports express configuration in AWS CloudFormation for infrastructure as code deployment. This launch enables you to automate the infrastructure deployment of your Aurora clusters through CloudFormation templates while benefiting from the speed of express configuration.

Aurora PostgreSQL clusters created with express configuration allow you to create and query an Aurora serverless database in seconds. The fresh withExpressConfiguration createOnly property on the AWS::RDS::DBCluster resource creates both the cluster and its primary database instance from one property declaration. You don't need to model or manage the instance separately in your CloudFormation template. This simplifies your templates and makes it easier to manage Aurora clusters with express configuration through infrastructure as code.

Recent findings suggest that the CloudFormation support is available in all AWS Regions where Aurora PostgreSQL with express configuration is offered. To learn more, see the Aurora User Guide and the AWS::RDS::DBCluster resource reference in the AWS CloudFormation documentation.
