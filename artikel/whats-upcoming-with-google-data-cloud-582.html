What’s upcoming with Google Data Cloud

🌐 Source: Google • 📅 12 Nov 2026 • ⏱️ 18 min read (3607 words, 📚 Deep Dive)
💡 Key Takeaways
  • Bringing conversational analytics to Gemini with Data Cloud connectors: Data Cloud connectors in Gemini are now in preview, enabling knowledge workers to query live enterprise data using natural language directly within tools like Google Docs, Gmail, and Google Slides.
  • Direct Apache Iceberg access in AlloyDB enables unified lakehouse querying: AlloyDB for PostgreSQL now supports direct querying of Apache Iceberg tables stored in Cloud Storage without requiring ETL pipelines or data duplication.

Bringing conversational analytics to Gemini with Data Cloud connectors: Data Cloud connectors in Gemini are now in preview, enabling knowledge workers to query live enterprise data using natural language directly within tools like Google Docs, Gmail, and Google Slides. The capability connects across BigQuery, Looker, Spanner, AlloyDB for PostgreSQL, and Cloud SQL without requiring data movement, grounded by Knowledge Catalog semantic models under user-identity IAM governance. Read the announcement blog.

Direct Apache Iceberg access in AlloyDB enables unified lakehouse querying: AlloyDB for PostgreSQL now supports direct querying of Apache Iceberg tables stored in Cloud Storage without requiring ETL pipelines or data duplication. Transactional applications can join operational data with analytical lakehouses in real time using standard PostgreSQL queries, accelerating cross-system analysis while maintaining complete relational integrity. Together with AlloyDB sync and lakehouse federation, you now have three integration approaches to choose from, depending on your use case. Read the launch blog.

Sources indicate that alloyDB Express delivers instant scale-to-zero PostgreSQL for developer prototyping: AlloyDB Express is now available, providing a lightweight, fast-provisioning PostgreSQL environment tailored for developers, testing, and AI coding agents like Antigravity. It scales to zero when idle to minimize costs while maintaining full PostgreSQL compatibility, allowing engineering teams to transition prototype workloads to production AlloyDB instances when ready. AlloyDB Express offers a free tier, with easy-to-understand pricing for higher usage. Read the announcement blog.
