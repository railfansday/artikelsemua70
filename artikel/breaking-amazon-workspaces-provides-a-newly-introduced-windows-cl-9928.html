Breaking: Amazon WorkSpaces provides a newly introduced Windows client experience

🌐 Source: Amazon • 📅 17 Nov 2026 • ⏱️ 1 min read (157 words, 📖 Standard)
💡 Key Takeaways
  • Amazon WorkSpaces provides a fresh Windows client experience for Amazon WorkSpaces Personal.
  • WorkSpaces Advisor proactive troubleshooting (Public Preview) is an intelligent latest capability that monitors key metrics from your device, network, and the WorkSpace itself, and provides you with actionable recommendations if there are challenges with registration, sign-in, or the connection in general.
  • The upcoming client experience is available at no additional cost in all AWS Regions where Amazon WorkSpaces Personal is available.

Amazon WorkSpaces provides a fresh Windows client experience for Amazon WorkSpaces Personal. The new client experience includes an updated interface, a simplified connection flow, easier-to-find settings, and the new WorkSpaces Advisor proactive troubleshooting (Public Preview) that suggests actions you can take to resolve common problem.

WorkSpaces Advisor proactive troubleshooting (Public Preview) is an intelligent latest capability that monitors key metrics from your device, network, and the WorkSpace itself, and provides you with actionable recommendations if there are challenges with registration, sign-in, or the connection in general. The new client experience also includes an improved full screen experience, a welcome tour to help orient you, and for WorkSpaces that are admin-enabled, a self-service option to enable nested virtualization.

The upcoming client experience is available at no additional cost in all AWS Regions where Amazon WorkSpaces Personal is available.

To learn more, visit the Amazon WorkSpaces Windows client documentation or download the Amazon WorkSpaces client.
