AWS License Manager now supports AWS Managed Microsoft AD (Hybrid Edition)

🌐 Source: Amazon • 📅 19 Nov 2026 • ⏱️ 1 min read (130 words, ⚡ Quick Read)
💡 Key Takeaways
  • Previously, onboarding Microsoft user-based subscriptions required a trust relationship between your directory and a second directory in AWS.
  • In a recent development, this feature is available in all AWS Regions where AWS License Manager user-based subscriptions and AWS Managed Microsoft AD (Hybrid Edition) are available.

Previously, onboarding Microsoft user-based subscriptions required a trust relationship between your directory and a second directory in AWS. If your security policies didn't allow that trust, you couldn't onboard without changing those policies. Now, license-included Microsoft Office and Visual Studio instances that you launch on Amazon Elastic Compute Cloud (Amazon EC2) join your existing directory and apply the same Group Policy settings, such as security baselines and audit policies, so you don't need to recreate them in a second directory.

In a recent development, this feature is available in all AWS Regions where AWS License Manager user-based subscriptions and AWS Managed Microsoft AD (Hybrid Edition) are available. To learn more, see the AWS License Manager User Guide, or get started in the AWS License Manager console.
